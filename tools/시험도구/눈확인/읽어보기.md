# 눈 확인 도구

이 도구는 `눈으로_확인할_것.md`의 줄마다 그 화면까지 자동으로 데려다 주고, 창을 연 채 멈춤. "다음" 신호가 오면 뒤에서 미리 준비해 둔 다음 장면을 바로 보여 줌.

- 서버·DB: e2e 브라우저 시험과 같은 것 (시험 백엔드 4100·화면 5273/5274/5275·시험 DB `joker_e2e`). 4000번 개발 서버·개발 DB는 안 씀
- 잠금: `with-lock.sh e2e`를 스스로 잡음 → 브라우저 시험과 같이 안 돎
- 흔적: `tools/시험도구/.run/eyecheck/` (git에 안 올라감)

## 1. 돌리는 법

```bash
bash tools/시험도구/눈확인/run.sh            # 처음 장면부터, 창 보임
bash tools/시험도구/눈확인/run.sh 바-01      # 그 번호부터
bash tools/시험도구/눈확인/run.sh --only 가  # 가 묶음만 (쉼표로 여럿: --only 가,마-03)
bash tools/시험도구/눈확인/run.sh --selfcheck   # 창 없이 전부 준비 → 사진 shots/<번호>.png, 실패 목록
```

- 서버가 이미 떠 있으면 그대로 쓰고, 안 떠 있으면 켬 (화면 빌드가 낡았으면 1~3분 빌드)
- 끝나면 연 창·봇·켠 서버를 닫고, 이번에 만든 시험 계정을 지움
- CPU를 5초마다 적고 끝에 평균·최고를 한 줄로 보여 줌 (`cpu.txt`)

## 2. 신호 주는 법

| 하고 싶은 것 | 터미널 | 신호 파일 `tools/시험도구/.run/eyecheck/next` |
|---|---|---|
| 다음 장면 | Enter | 빈 파일 (또는 `next`) |
| 앞 장면 | `prev` | `prev` |
| 그 번호로 | `goto 바-07` | `goto 바-07` |
| 지금 장면 새로 | `again` | `again` |
| 끝내기 | `stop` (또는 Ctrl+C) | `stop` |

```bash
touch tools/시험도구/.run/eyecheck/next                       # 다음
echo "goto 가-16" > tools/시험도구/.run/eyecheck/next          # 번호로
```

- 지금 상태: `status.json` — 지금 번호·볼 것·준비됐는지(`now.ready`)·덧붙임(`now.notes`)·다음 장면 미리 준비됐는지(`next`)·남은 줄 수(`left`)·지난번 바꾸는 데 걸린 시간(`lastSwitch.ms`)
- 바꾼 기록: `times.jsonl`, 진행 글: `run.log`, 서버 기록: `server-*.log`

## 3. 창

- 앞사람부터 화면(모니터) 수만큼 실제 크기 창(PC 1280×800, 폰 375×812), 나머지는 0.45배로 줄인 창 (글이 작아도 같은 화면)
- 큰 창은 주 화면부터 화면마다 하나씩, 줄인 창은 주 화면의 큰 창 오른쪽 남은 칸에 위→아래 (줄인 창은 다른 화면 좌표가 어긋나서 주 화면에만). 자리가 모자라면 비스듬히 겹침(`now.overlap`)
- 다음 장면은 내려 둔(최소화) 창에서 준비하고, 지나간 장면 창은 닫음 → 창 묶음은 늘 둘까지
- 알림창(`window.alert`)은 사람이 직접 닫음 (창 없는 모드는 글만 `now.alerts`에 적음)

## 4. 장면 쓰는 법

- 묶음마다 파일 하나: `scenes/ga.js`(가) · `na.js`(나) · `da.js` · `ra.js` · `ma.js` · `ba.js` · `sa.js` · `a.js`(아) · `ja.js`. 한 묶음을 둘이 나눠 쓰면 `ba-2.js`처럼 따로
- `ma.js`·`ba.js`엔 증명용 장면이 하나씩 있음 → 그 묶음 맡은 사람이 이어 씀
- 이름이 `_`로 시작하는 파일은 장면으로 안 읽음 (묶음 도우미 자리, 예: `scenes/_ba-kit.js`)
- 차례는 번호로 저절로 정해짐 (가→자, 같은 번호가 두 파일에 있으면 시작 때 멈춤)
- 뼈대(`run.js`·`lib/`)는 고치지 않아도 됨

장면 하나 = 배열 한 칸. 들어가는 법·통과 글은 목록 글에서 번호로 채워짐: `reports/최종보고_2026-11-16/눈으로_확인할_것.md` 먼저, 없으면 사본 `docs/맥북_이어받기_2026-11-17/눈으로_확인할_것.md` (`reports/`는 git에 안 올라감, 둘 다 없으면 `how`·`look`을 직접 씀).

```js
'use strict';
// 나 묶음 장면 (혼자 폰)
const { fromE2e } = require('../lib/paths');
const k = fromE2e('tests/auth/_a11b-kit');   // e2e 도우미를 그대로 불러 씀

module.exports = [
    {
        id: '나-05',
        needs: ['mobile'],                    // 켤 화면 서버 (기본 ['desktop'], 'admin'도 있음)
        async prepare(s) {                    // 그 화면까지 감 (미리 준비 때 뒤에서 돎)
            const me = await s.person({ mobile: true });   // 새 계정·로그인·로비
            await k.gotoMyPage(me.page);
            s.note('사용자에게 보일 덧붙임 한 줄');
        },
        // show(s): 보여 줄 때 할 일 (시간이 흐르면 안 되는 것, 예: 판 시작·1분 글)
        // still(s): 아직 그 자리인지 → false면 status에 "지나감"
        // manual: '까닭' → 손으로 해야 하는 줄 (prepare는 있어도 되고 없어도 됨)
    },
];
```

`s`(장면 묶음)가 주는 것:

| 것 | 무엇 |
|---|---|
| `s.person({ mobile, big, account, login, lobby, contextOptions, label })` | 사람 창 하나 (새 계정·API 로그인·로비). `login: false`면 로그아웃 빈 창 |
| `s.spawnBots(n)` | 소켓 봇 n개 (장면이 닫히면 닫힘) |
| `s.adopt({ context, page, kind, label })` | 도우미가 직접 만든 창(예: 관리자 창)을 장면에 넣음. 브라우저는 `await s.windows.browser('big')` |
| `s.note(글)` · `s.keep(fn)` · `s.background(promise)` | 덧붙임 글 · 닫을 때 할 일 · 뒤에서 도는 일 |
| `s.state` · `s.chained` · `s.main` · `s.people` | 엮인 장면끼리 넘기는 값 · 이어 받았는지 · 첫 사람 창 · 연 창 목록 |

## 5. 판 안 장면 (한 판으로 엮기)

- 같은 판을 이어 보는 장면은 `chain: '바-판'`처럼 같은 이름을 붙임 → 바로 앞 번호 장면의 `s`를 그대로 받음 (`s.chained === true`, 창·판 그대로)
- 엮인 장면은 미리 준비하지 않음 ("다음" 신호 때 판을 다음 자리까지 굴림, 손잡이라 몇 초)
- `prepare`는 처음부터 와도(goto·prev·again) 되게 씀:

```js
const { chainTable } = require('../lib/table');
{
    id: '바-07', chain: '바-판',
    async prepare(s) {
        const t = await chainTable(s, { people: 1 });    // 앞 장면 판이 있으면 그대로, 없으면 새 판
        t.playBots({ dayVote: 'skip', tribunal: 'skip', night: 'skip' });
        await t.advanceUntil('DAY_VOTE');                // e2e Table 손잡이로 그 자리까지
    },
}
```

- 단계 시간은 서버가 받는 가장 긴 값(토론 150·투표 90·재판 120·밤 120초, `lib/table.js` ROOMY). **멈추는 수단은 없음** → 오래 보면 판이 넘어가니 `still`로 알리고 `again`으로 다시 준비
- 역할 확인 창은 10초 뒤 저절로 닫힘 → `ba.js` 바-01처럼 "내 역할 보기"로 다시 열어 둠

## 6. 맥에서 돌릴 때 바꿀 곳

윈도우에서만 만들고 시험함. 맥에서는 아래를 바꿔야 함 (아직 안 고침).

| 자리 | 지금 | 맥에서 |
|---|---|---|
| `run.sh:19` | CPU 재기를 PowerShell로 | `top -l 1` 등으로 바꿈 |
| `lib/servers.js:39~40` | 서버 끄기를 `taskkill /T`로, 그 밖은 `process.kill(-pid)` | `:100` spawn에 `detached: true`를 넣어야 `-pid`(묶음 끄기)가 먹음 (지금은 자식 백엔드가 안 죽을 수 있음) |
| `lib/servers.js:46` | 윈도우가 아니면 `isOurServer`가 늘 참 → 지난번 남은 PID를 확인 없이 끔 | `ps -o command= -p <pid>`로 e2e 서버 스크립트인지 보고 끔 |
| `lib/windows.js:18~20` | 화면(모니터) 정보를 PowerShell로 읽음, 윈도우가 아니면 1920×1032 하나로 가정 | `system_profiler SPDisplaysDataType`·AppleScript로 읽음 |
| `lib/windows.js:12`·`:86` | 작은 창 배율 0.45(`--force-device-scale-factor`), 큰 창 바깥 크기 1296×888 가정 | 윈도우 100% 화면 배율에서 잰 값 → 레티나·맥 창 테두리에서 다시 잼 |
| `lib/windows.js` arrange | 줄인 창은 주 화면에만 둠 (윈도우에서 다른 화면 좌표가 어긋남) | 맥에서 다시 확인 |

- 나머지(Playwright·e2e 도우미·신호·장면 파일)는 운영체제와 상관없음
