# 여러 계정 도구

크롬 창 하나에 계정 5~10개의 게임 화면을 띄워 두고, 아래 띠 단추(또는 Alt+숫자)로 칸을 바꿔 가며 직접 해 보는 도구임. 칸마다 로그인이 따로 남고, 안 보는 칸도 꺼지지 않음.

## 1. 켜기

```bash
# 1) 게임 백엔드를 먼저 켬 (개발 백엔드 4000번)
npm run dev --prefix backend

# 2) 도구 켜기 (칸 8개)
node tools/시험도구/여러계정/start.js --count 8
```

- 처음엔 PC·폰 화면을 빌드함 (몇 초~1분). 화면 코드가 바뀌었으면 켤 때 다시 빌드함
- 크롬 창 하나가 뜨고 칸마다 로그인 화면이 보임 → 칸마다 계정으로 직접 로그인
- "로그인 상태 유지"를 켜고 로그인하면 도구를 껐다 켜도 그 칸에 로그인이 남음 (안 켜면 창을 닫을 때 풀림)
- 끄기: 켠 터미널에서 Ctrl+C (또는 창 닫기)
- 화면 서버(5173·5174)는 안 켜도 됨 — 도구가 자기 빌드본을 씀

| 옵션 | 뜻 |
|---|---|
| `--count 8` | 칸 수 1~10 (안 주면 지난번 값, 처음은 6) |
| `--api http://localhost:4000` | 게임 백엔드 주소 (기본 4000 = 개발 백엔드) |
| `--port 5390` | 도구 서버 포트 (기본 5390) |
| `--rebuild` / `--no-build` | 화면을 꼭 다시 빌드 / 빌드 안 함 |
| `--no-open` | 창을 안 띄움 → 내 크롬·엣지에서 `http://multi.localhost:5390/` 를 직접 엶 |

## 2. 쓰는 법

| 하고 싶은 것 | 어떻게 |
|---|---|
| 칸 바꾸기 | 아래 띠 칸 단추 · **Alt+1~9, Alt+0(10번)** · 띠를 누른 뒤엔 숫자만 눌러도 됨 |
| 전부 작게 보기 | "모두 보기" · **Alt+G** → 칸을 누르면 그 칸이 크게 |
| 칸 새로고침 | "새로고침"(고른 칸) · 모두 보기에서 칸 머리의 "새로고침" |
| PC ↔ 폰 화면 | "폰으로/PC로"(고른 칸) · 모두 보기 칸 머리의 "→ 폰" — 그 칸만 새로고침되고 로그인은 그대로 |
| 이름표 | "이름표" 또는 칸 단추 두 번 누르기 (비우면 로그인 닉네임이 보임) |
| 칸 수 | "칸" 고르기 5~10 — 줄이면 빠지는 칸 계정은 게임에서 끊김 (물어봄) |
| 소리 | "고른 칸만"(기본) · "모두" · "끔" |

- 게임 입력칸에 숫자를 쓰는 건 안 가로챔 (칸 바꾸기는 Alt를 같이 누른 것만)
- 띠 오른쪽 점: 초록 = 백엔드 붙음, 빨강 = 백엔드 안 켜짐
- 칸 단추 아래 작은 글: PC/폰 · 그 칸의 지금 화면 주소 (/lobby, /ingame …)
- 칸 수·PC/폰·이름표는 `tools/시험도구/.run/multi/state.json`에 남음 (git에 안 올라감)

## 3. 어떻게 칸마다 로그인이 갈리나

- 로그인은 쿠키(httpOnly)라 같은 주소면 칸끼리 섞임 → 칸마다 주소를 다르게 함: `p1.multi.localhost:5390` … `p10.multi.localhost:5390` (크롬은 `*.localhost`를 내 컴퓨터로 봄)
- 겉 화면은 `multi.localhost:5390` — 칸과 같은 사이트라 칸 안(iframe)에서도 로그인 쿠키(SameSite=Lax)가 실림
- 화면이 부르는 서버 주소를 "그 칸 주소"로 바꿔 빌드함 (`build.mjs`, 앱 코드 파일은 안 고침) → 도구 서버가 `/auth`·`/user`·`/game`·`/socket.io` … 를 백엔드로 넘김
- 넘길 때 칸 주소 Origin만 뺌: 백엔드 허용 주소에 칸 주소가 없어서. Origin이 없으면 개발 백엔드는 받아 줌 (운영 백엔드는 거절 → 운영 서버엔 못 씀)

## 4. 안 되는 것·알아 둘 것

- 구글·디스코드 로그인은 안 됨 (백엔드가 정해 둔 화면 주소로 돌아감) → 이메일 로그인만
- 계정은 도구가 안 만듦. 개발 시험 계정이 필요하면 백엔드 쪽 `scripts/seed-dev-testers.js` 안내를 따름
- 칸 10개면 메모리를 꽤 씀 (칸마다 게임 화면 하나) — 느리면 칸 수를 줄임
- 내 크롬으로 열 땐(`--no-open`) 안 보는 칸 소리가 켤 때 잠깐 멈출 수 있음 (크롬 자동 재생 규칙). 도구 창은 괜찮음
- 화면 코드를 고쳤으면 도구를 다시 켬 (켤 때 빌드본이 낡았으면 다시 빌드)
- 진짜 서버에서 확인함 (2026-11-26, 시험 백엔드 `--api http://localhost:4100`·시험 DB): 칸 5개 이메일 로그인 → 칸마다 자기 닉네임 → 1번 칸 방 만들기 → 2~5번 칸 코드 입장(5번은 폰 화면) → 준비·시작 → 5칸 모두 판 화면·역할 창. 1번 칸만 보는 동안(대기방 60초·판 30초) 다른 칸이 안 빠지고 판도 같이 넘어감. 칸 10개 로그인까지 됨
- 칸 10개를 처음 띄울 땐 CPU 가 잠깐 100% 가까이 오름 (칸은 0.4초 간격으로 차례로 뜸). 10칸이면 아래 띠 앞쪽 칸이 옆으로 밀려 안 보임 → 띠를 옆으로 굴리거나 Alt+숫자
- 시험 백엔드(4100)에 e2e 모양 계정(`e2e+…@example.test`)으로 놀면, 다음 e2e 실행이 시작할 때 6시간 넘은 그 계정을 지움 → 오래 쓸 계정은 개발 백엔드(4000) 쪽 시험 계정을 씀

## 5. 스스로 확인

```bash
node tools/시험도구/여러계정/check.js            # 가짜 백엔드로 확인 (진짜 백엔드·DB 안 씀)
node tools/시험도구/여러계정/check.js --shots <사진 폴더>
```

- 칸 5개 뜸 · 단추/숫자/Alt+숫자로 바뀜 · 입력칸 숫자는 안 가로챔 · 칸끼리 localStorage·쿠키 안 섞임 · 로그인 쿠키·소켓이 그 칸 것으로 넘어감 · 숨은 칸 소켓·타이머가 살아 있음 · 폰 화면 바꾸기 · 이름표 · 칸 수 바꾸기
- 포트 5392(도구)·5393(가짜 백엔드)을 잠깐 씀

## 6. 파일

| 파일 | 하는 일 |
|---|---|
| `start.js` | 켜기 (빌드 → 서버 → 창) |
| `build.mjs` | PC·폰 화면 빌드 (서버 주소만 "그 칸 주소"로) → `.run/multi/front/` |
| `server.js` | 겉 화면·칸 화면·백엔드 넘기기 (포트 하나) |
| `shell.html` | 겉 화면 (칸·아래 띠) |
| `slot.js` | 칸 화면에 끼워 넣는 도우미 (Alt+숫자 넘기기·지금 주소·닉네임·소리 끄기) |
| `check.js` | 스스로 확인 |
