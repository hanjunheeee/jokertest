\# 상단 day/phase 인디케이터에 현재 턴 표기 통합 (frontend)



\## 배경

인게임 우상단에 기존 day/phase 인디케이터("제 N일" + phase 아이콘 바)가 있다. 현재 턴

안내는 오버레이("광대의 시간입니다" 등)로만 지나가 닫히면 누구 차례인지 화면에 남지

않는다. 새 컴포넌트를 만들지 말고 이 기존 인디케이터를 수정해 현재 상태 문구를 함께

표시한다. 이번 작업은 frontend만 다룬다. backend는 수정하지 않는다.



\## 요구사항

1\. 기존 day/phase 인디케이터 컴포넌트에 상태 문구를 추가한다:

&#x20;  - NIGHT: 현재 canonical 턴 역할 기준 "광대의 시간입니다" / "의사의 시간입니다" 등

&#x20;    (기존 밤 턴 안내 문구 상수를 재사용한다 — 문구를 새로 만들지 않는다)

&#x20;  - DAY: "낮 — 토론과 투표"

&#x20;  - TRIBUNAL: "재판 진행 중"

&#x20;  - ENDED: 문구를 표시하지 않는다(인디케이터 기존 표시는 유지)

2\. store의 canonical phase·night turn 값에서만 파생한다(별도 소켓 구독·타이밍 로직 금지).

&#x20;  NIGHT 턴 계산에 기존 파생 로직(밤 턴 안내가 쓰는 것)이 있으면 재사용한다.

3\. 기존 인디케이터의 현재 표시("제 N일", phase 아이콘)와 레이아웃 골격은 유지하고,

&#x20;  문구는 그 관례(폰트·색)에 맞춰 자연스럽게 붙인다.

4\. 새 컴포넌트 파일을 만들지 않는다 — 기존 인디케이터 컴포넌트(및 필요 시 그 상수 파일)

&#x20;  수정으로 해결한다. 파생 순수 함수 유틸 1개 신설은 허용한다.



\## 수정 금지

\- backend/\*\*, e2e/\*\*

\- 밤 턴 안내 오버레이 자체의 동작

\- 인디케이터의 기존 day/phase 표시 로직



\## 검증

\- 파생 함수 단위 테스트: phase×턴 조합별 문구, ENDED에서 null

\- 인디케이터 DOM 테스트: NIGHT 턴 변경 시 문구 갱신, DAY/TRIBUNAL 문구

\- 기존 frontend 전체 테스트 PASS, frontend build PASS
