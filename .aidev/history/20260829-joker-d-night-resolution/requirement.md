# joker-D · 밤 해소 규칙 명세화

## 확정 스펙 (전제)

- 판정 순서: 보호 대조 → 사망 확정 → 사망자의 잔여 효과 소멸
- 승리 재평가 원칙: "사망 이벤트 직후 항상" (처형·밤 사망·끊김 사망 공통 — C·S3와 공유)

## 요구

1. **보호 성공 시 광대에게 실패 통지**: 광대의 암살 대상이 의사의 보호 대상과 일치하면 대상은 죽지 않고, 광대(들)에게 "암살 실패" 통지가 간다. 통지에는 실패 사실만 담고 보호자·사유는 담지 않는다. 다른 플레이어에게는 사망 없는 밤으로만 보인다.
2. **의사 사망 시 보호 소멸 명문화**: 암살 대상이 의사 본인(자기보호 아님)이면 의사는 사망하고, 그가 타인에게 건 보호는 소멸한다. 현 스펙(킬 소스 광대 1종)에서는 관측 불가능한 규칙이나, 판정 순서를 코드에 명시하고 테스트로 고정한다 (미래 킬 직업 추가 대비).
3. **경비원 조사와 대상 사망의 독립**: 경비원이 조사한 대상이 같은 밤 암살되어도 조사 결과(role)는 정상 통지된다.
4. **밤 사망 직후 승리 재평가**: 밤 결과 해소로 사망이 확정되는 즉시 승리 조건을 재평가한다 (낮 진입 전).

## 성공 조건

- 의사가 광대의 대상을 보호한 밤: 대상 생존 + 광대에게만 실패 통지 + 통지에 보호자 정보 없음
- 의사가 암살당한 밤: 의사 사망, 타인 보호 소멸이 판정 순서 테스트로 고정된다
- 경비원 조사 대상이 같은 밤 사망해도 조사 결과가 통지된다
- 밤 사망으로 광대 전멸 시 낮 진입 없이 즉시 시민 승리 / 시민 수 = 광대 수 도달 시 광대 승리
