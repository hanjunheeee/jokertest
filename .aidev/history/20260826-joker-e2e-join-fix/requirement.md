\# E2E 입장 경로 수정 — 방코드 입력 → 공개 방 목록 (e2e)



\## 배경 (실행에서 확인된 사실)

첫 E2E 실행에서 joinByCode가 /roomInvite 방코드 입력으로 입장을 시도했으나, 방코드 입력

기능은 아직 미구현이다(6자리 입력이 정상 동작하지 않음 — 실행 스크린샷으로 확인).

실제 입장 경로는 로비/게임플레이의 공개 방 목록에서 방을 클릭해 들어가는 방식이다.

매칭 화면의 카운트다운 표시는 하드코딩된 더미이므로 무시한다.

이번 작업은 e2e/\*\* 만 다룬다. frontend·backend는 수정하지 않는다

(단, 공개 방 목록에 셀렉터로 쓸 수 있는 data/role/텍스트가 전혀 없어 접근이 불가능한

경우에만 해당 목록 컴포넌트에 data-e2e 속성을 최소 추가하고 그 목록을 plan에 명시한다).



\## 요구사항

1\. e2e/lib/actors.js의 joinByCode를 공개 방 목록 입장으로 대체한다:

&#x20;  해당 좌석이 공개 방 목록 화면으로 이동 → 방장(S1)의 방을 식별해 클릭 입장 →

&#x20;  /game-matching 도달 대기. 목록에 방이 아직 없으면 나타날 때까지 대기한다

&#x20;  (목록 갱신 방식은 frontend 소스를 조사해 따른다).

2\. readRoomCode(초대코드 모달)가 불필요해지면 호출 경로에서 제거한다.

3\. 시나리오 spec·scenarioPlan의 입장 단계를 새 경로에 맞게 갱신한다.

&#x20;  입장 순서(S2→S3→S4→S5)는 역할 배정 순서이므로 반드시 순차 유지.

4\. 방 식별은 기존 data-\*/role/텍스트 셀렉터 우선. frontend의 공개 방 목록 컴포넌트

&#x20;  소스를 조사해 정확한 셀렉터를 쓴다.



\## 검증

\- 갱신된 헬퍼 단위 테스트 PASS, e2e 헬퍼 테스트 전체 PASS

\- 기존 frontend 전체 테스트 PASS
