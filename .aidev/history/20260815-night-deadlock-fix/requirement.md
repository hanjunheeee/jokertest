# 밤 페이즈 사망자 교착 버그 수정

## 배경
가드 조사 slice(20260815-guard-inspect)의 plan §5에서 발견된 기존 버그.
해당 slice는 범위 준수를 위해 수정하지 않고 보고만 했다.

## 증상 (가드 plan의 관찰, implement 전 코드 기준)
밤 페이즈에서 사망한 플레이어가 밤 행동 제출 대상에서 제외되지 않아,
사망자가 제출하지 않으면 밤 판정이 시작되지 못하고 게임이 교착된다.
(정확한 재현 조건과 현재 코드 상태는 plan에서 다시 검증할 것 —
 가드 slice의 변경으로 상황이 달라졌을 수 있다)

## 요구 동작
1. 밤 행동 제출 완료 판정은 "생존한 행동 보유자" 기준으로만 계산된다.
2. 사망자는 밤 행동 제출 UI 대상에서 제외되고, 제출 시도는 거부된다.
3. 밤 도중 사망(불가능하다면 명시)과 밤 시작 전 사망을 구분해 처리한다.
4. 기존 판정(가드 조사 R1~R4 포함) 회귀 없음.

## 명확히 할 규칙
- 모든 행동 보유자가 사망한 밤: 즉시 판정으로 넘어가는가?
※ 기존 코드에 정해진 동작이 있으면 따르고, 없으면 선택지+추천안 제시.

## Scope (우선 탐색)
- backend/game-core/gameSession.js (가드 slice에서 검증된 실제 경로)
- backend/game-core/__tests__/gameSession.test.js
- backend/socket/ 하위 제출 경로

## 테스트
- 사망자 미제출 상태에서 밤 판정이 정상 진행되는 케이스
- 사망자 제출 거부 케이스
- 전원 사망 밤의 확정 동작 케이스
- 기존 345개 회귀 없음

## 하지 않는 것
- UI 변경 / 다른 직업 로직 / 새로고침 세션 문제 (별도 slice)
