# joker-B · 프론트 표시·정보 전달 수정

## 배경

백엔드 판정은 정상인데 프론트에서 정보가 유실되거나 누출되는 경로 4건.

## 요구

1. 플레이어 색상(테마 인덱스) 배정을 백엔드로 이관한다. 게임 시작 시 백엔드가 무작위 배정해 game_started payload로 내려주고, 프론트의 Math.random() 셔플(assignInGamePlayerThemeIndices.js :8)은 제거하고 payload 값을 그대로 사용한다. 모든 클라이언트가 같은 플레이어에 같은 색을 본다.
2. WH·경비원의 비공개 조사 결과가 낮 전환 이벤트에서 초기화되지 않게 한다 (useInGameResolveNight.js :112의 nightActionResult 초기화 경로 수정). 결과는 해당 낮 동안 확인 가능해야 한다.
3. 사망자의 밤 채팅을 차단한다: 밤에는 DEAD 채널 열람·전송 모두 불가 (inGameChatChannel.js :12, :29). **예외: 죽은 광대는 JOKER 채널 열람·전송이 계속 가능하다** (확정 스펙 — 광대만의 특례, 다른 직업에는 해당 없음). 낮의 DEAD 채널 전송 가능 여부는 이 슬라이스에서 바꾸지 않는다 (S4에서 처리).
4. GUARD 한국어 표기를 "경비원" 하나로 통일한다 (경호원/경비대 표기 제거 — 등장 지점 전체).

## 성공 조건

- 서로 다른 두 클라이언트에서 같은 플레이어의 색이 동일하다 (8.9 / 11.5)
- WH가 조사 후 다음 낮에 결과를 화면에서 확인할 수 있다 (4.2.3 / 6.2)
- 사망자 클라이언트는 밤 동안 어떤 채팅도 보거나 보낼 수 없다 — 단, 죽은 광대의 JOKER 채널은 예외로 유지된다 (7.4 / 7.6 프론트 측)
- "경호원", "경비대" 문자열이 코드베이스에서 검색되지 않는다 (5.6)

## 성공 조건에 넣지 말 것 (범위 밖 — 수정 금지)
