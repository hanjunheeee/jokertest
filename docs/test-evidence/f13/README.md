## 재현한 결함과 최소 수정

살아 있는 본인의 새로고침에서 사망자·끊김 참가자 혼합 화면은 정상 복원됐다(AX-d6e5-dead-reconnect.png). 그러나 사망자 본인이 새로고침하면 전체 게임이 사라졌다. 원인은 onDisconnect가 사망자의 getDisconnectGraceTarget=null을 게임 종료로 오해하여 endGameSessionForPlayer로 전체 세션을 삭제하는 것이었다. 이미 사망한 참가자는 탈락 유예 타이머가 필요 없지만 진행 중인 게임의 재접속 권리는 유지해야 한다.

backend/socket/gameSession.js에서 기존 canonical UUID/expectedGameId 스냅샷으로 진행 중인 세션임을 확인하면 종료 정리로 떨어지지 않게 했다. 생존자 유예/탈락과 실제 종료 정리는 그대로 유지한다. DAY/TRIBUNAL/NIGHT의 사망자 disconnect→정상 인증 소켓 resyncSessionRouting→get_session_snapshot 회귀3개를 추가했다. 수정 전3개 모두 game_ended 발생 단언에서 실패, 수정 후 기존 socket/day/night 타이머 테스트 포함231개 통과, 실패0/skip0. 이 부분 테스트는 공식 전체 테스트를 대체하지 않는다.
