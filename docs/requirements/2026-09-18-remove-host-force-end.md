# 방장 게임 강제 종료 기능 삭제

2026-09-18 사용자 지시: “게임 강제 종료가 설마 방에 있었니???이거 삭제해 이거 필요없어”.

- 인게임 설정의 방관리 탭에 있던 `force-end-game` 행을 삭제한다. 실제 소비처 `SettingRoomTab.handleRoomAction`은 추방만 연결하고 있어 강제 종료 동작은 구현되지 않은 상태였다.
- F-22/BG는 PLAN human, 구현 미시작·worktree 없음 상태에서 취소한다. 계획과 반려 기록을 monitor에 보존한 뒤 공식 `pluto/slices/delete`로 기존 배치에서 제외한다. 성공·병합·SKIP PASS로 세지 않는다.
- 기존 F-22 요구와 D-13, 최종 F-28의 방장 강제 종료 구현·검증 요구는 폐기한다. 옛 승인 JSON 및 실행 기록은 역사적 자료로 보존하며 재등록하지 않는다.
- F-28에서는 강제 종료 버튼이 다시 생기지 않았는지를 확인한다. 강제 종료용 서버 API·저장소·영수증·복구 알림을 새로 만들지 않는다.
- 방장 추방(F-21), 정상 승패 종료·경기 저장·보상·타이머 정리, 보안상 소켓 연결 종료는 삭제 대상이 아니다.
- F-23 관전자 제거, 죽은 참가자의 관전/나가기 선택, F-24 및 F-28 복원 조건과 그 밖의 승인 범위는 유지한다.
- 기존 32개 중 F-22 1개 취소: 남은 유효 범위는 31개. 완료는 여전히 21개이며 F-23부터 기존 순서대로 진행한다. 기존 배치·예약을 그대로 사용한다.
- 이번 UI 삭제는 사용자의 직접 삭제 요청에 대한 변경이다. 모니터가 다른 제품 결함을 임의 수정하도록 권한을 확장하지 않는다.
