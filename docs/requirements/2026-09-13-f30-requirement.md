# F30 피의 기록과 명성 제거

## 승인 및 기준
2026-09-13 사용자가 추가 구현 및 기존 배치 F28 이전 편성을 승인했다. 선행 F29 완료 후 F30→F31→F32 순서로 구현한다.

## 구현 요구사항

- 마이페이지 피의 기록은 **전체 판수와 승률 두 항목만** 표시한다. 현재 세 행의 생존 횟수·단두대 처형을 제거하고 전체 판수는 유지, 계정 전체 승률을 연결한다.
- 초안의 전체 판수·승률 삭제 또는 생존·처형 유지 지시는 폐기한다.
- 명성 이름·값·관련 장식·빈 자리를 로비 및 마이페이지 공통 프로필 배너를 포함한 사용자 화면에서 제거한다. 닉네임·칭호·장비·프로필은 보존한다.
- 승률은 계정 전체 유효 종료 경기의 승수/판수에 기존 서버 판정 기준을 적용한다. 기본 표시는 소수 첫째 자리, 0판은0.0%. 특정 직업의 최고 승률로 대체하지 않는다. 조회 실패를0판으로 위장하지 않는다.
- 업적·랭킹·운명의 가면이 소비하는 원본 판수·승수·생존·처형 집계는 보존한다. 미사용 명성 API/가공은 실제 소비처를 대조한 뒤 정리한다. DB 컬럼 물리 삭제는 별도 이관 검토 없이 실행하지 않는다.
- 인수: 정상/0판/실패/재시도/계정 전환/재로그인/새로고침에서 두 항목·계정별 값·명성 부재 확인, 확대 글자와 좁은 화면, 프로필 장비 및 기존 집계 회귀. 실제 Chrome에서 마이페이지와 로비를 확인한다.
