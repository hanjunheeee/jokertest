# F-23 후속 승인: 외부 관전자 입장 제거·사망 참가자 관전/나가기

2026-09-12 사용자가 사망 참가자의 관전 유지와 나가기 선택을 승인했다. 기존 F-23의 ‘관전자 전면 제거’ 문구보다 이 구분을 우선한다.

- 제거 대상은 경기에 참가하지 않은 외부 사용자의 관전자 전용 설정·입장·권한이다.
- 서버에서 사망이 확정된 기존 참가자는 ‘관전 계속하기’와 ‘나가기’를 선택할 수 있다. 관전을 계속하다가 나중에 나갈 수도 있다.
- 관전은 기존 참가자 자격으로 경기 종료까지 허용된 공개 진행·결과와 본인에게 허용된 영상을 수신하는 것이다. 생존자 투표·능력 권한이나 비밀 직업·진영·밤 행동 열람 권한을 새로 부여하지 않는다.
- 나가기는 명시적 사용자 선택으로 서버에 반영하고 게임 구독·화면을 정리한 뒤 로비로 이동한다. 실패 시 성공한 것처럼 이동하지 않고 오류·재시도를 제공한다. 중복 요청은 안전하게 처리한다.
- 명시적인 나가기와 일시적인 연결 끊김·새로고침을 구분한다. 관전 중 연결이 끊긴 사망 참가자의 기존 재접속 권한은 유지한다. 나가기 완료 후 자동으로 해당 경기에 다시 진입시키지 않는다.
- 한 참가자의 나가기가 남은 경기·타이머·다른 참가자의 구독을 종료하거나 기존 참가 기록을 지우지 않도록 한다. 승패·보상·이탈 처리는 기존 확정 정책을 보존한다.
- 밤의 잠정 피격과 치료 가능 상태를 최종 사망으로 오인하지 않는다. 관전/나가기 선택 노출 시점은 서버 판정과 일치시킨다.

## 필수 인수 검증

1. 사망 확정 후 선택 UI가 나타나고 관전 계속하기로 실제 경기가 갱신된다.
2. 사망 관전 중 새로고침·연결 복구 후 같은 참가자 상태로 복원된다.
3. 나가기 및 관전 중 나중에 나가기 후 로비로 이동하고 자동 재진입하지 않는다.
4. 나가기 실패·재시도·중복 요청에도 남은 참가자의 경기 진행과 데이터가 보존된다.
5. 외부 사용자는 URL/API/소켓으로 관전할 수 없고, 사망 참가자는 직접 요청으로 투표·능력·비밀 정보에 접근할 수 없다.
6. 서버·프론트 회귀와 실제 다중 사용자 Chrome 검증을 F-23 및 최종 F-28에 포함한다.

기존 Pluto 배치 BH(F-23)를 그대로 사용한다. 배치 입력 사본과 상세 요구사항을 갱신하되 daemon state.json은 직접 수정하지 않는다. BH의 AC/계획 생성 시 본 후속 승인을 반영하고, 생성 결과가 누락하면 공식 acceptance/plan 수정 경로로 바로잡는다.
