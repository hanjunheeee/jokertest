## 확인 결과와 구현 시 준수 사항

5개 모두 1280×720, 24fps, ProRes 영상이며 픽셀 형식은 `yuva444p12le`이다. 모두 PCM 오디오 트랙이 존재한다. 사용자가 게임 내 사용·배포 허락 확인 질문에 **“영상속 사운드는 가능해”**라고 답하여 위 5개 파일에 포함된 사운드 사용을 명시적으로 확인했다(2026-09-10). 이 확인은 해당 제공 영상에 한정하며 별도 BGM·다른 미확인 소리에 대한 허용으로 확대하지 않는다.

1. 영상 제공 상태는 수령 완료다. 아직 웹용 변환·브라우저 재생·실제 게임 이벤트 연결은 완료하지 않았다.
2. F-27에서 실제 화면 내용을 검토하고 기존 오버레이에 맞게 알파 채널을 보존하는 웹 재생용 변환을 수행한다. 컨테이너 정보만으로 투명도·재생 호환성을 검증 완료로 처리하지 않는다.
3. **후속 사용자 확인에 따라 위 5개 영상의 내장 사운드는 사용한다.** 이전의 이 파일들에 대한 오디오 제거·강제 무음 지시는 철회한다. 웹 변환 시 영상의 알파와 함께 오디오를 보존하거나 같은 영상에 동기화되는 형태로 변환한다. Master×SFX와 사용자 음소거 설정을 적용하며, 동일 사건에 영상 내장음과 별도 성공 효과음을 중복 재생하지 않는다. 별도 BGM 및 다른 출처 미확인 소리는 기존 금지·무음 정책을 유지한다.
4. 역할 연결 표는 파일명에 근거한다. 사용자·대상자 수신 정책은 승인된 F-25~F-27/D-14를 따른다. 경비원·마녀사냥꾼 파일의 대상자 화면 적용은 실제 영상 내용을 확인하고 비공개 정보 노출 없이 연결한다. 새 역할 공개 정책을 임의 추가하지 않는다.
5. 광대 킬과 같은 밤 의사 회복은 각각의 연출을 모두 보여준 후 최종 생존 상태를 반영한다. 영상 완료·오류·재접속에 따른 후속 턴 처리도 기존 인수 조건대로 검증한다.
6. 압축 파일명은 CP949로 해독했다. 깨진 이름으로 추출하거나 사용자 다운로드 원본을 덮어쓰지 않는다.

7. F-16·F-27·F-28은 위 제공 자산의 영상·음성 동기, 볼륨·음소거, 수신자 제한, 중복 재생 방지와 브라우저 재생을 검증한다. 자동재생 제한이나 오디오 오류가 밤 진행을 영구 대기로 만들지 않게 하고 실제 검증 결과를 기록한다.
