5. **개별 구매:** 한 상품의 차감·소유권 지급·거래 기록을 하나의 트랜잭션으로 처리한다. 잔액 부족·미판매·기보유·잘못된 상품·검증 실패·커밋 전 DB 오류이면 해당 구매의 골드/다이아 차감 0, 지급 0, 성공 거래 기록 0이어야 한다.
6. **일괄 구매:** 선택한 실제 판매 상품 전체를 한 트랜잭션으로 처리한다. 한 품목이라도 실패하거나 총액이 부족하면 묶음 전체를 실패 처리하여 모든 재화 차감 0, 모든 상품 지급 0, 성공 거래 기록 0으로 되돌린다. 일부 상품만 성공하거나 이미 보유한 상품을 임의로 건너뛰지 않는다.
7. 여러 개의 개별 구매는 각각 독립 거래다. 뒤의 개별 요청 실패가 이미 성공한 다른 개별 거래를 취소하지 않는다.
8. **응답 유실/타임아웃:** 서버 커밋 여부를 모르는 상태를 확정 실패로 표시하지 않는다. 개별/일괄 모두 같은 요청 식별자로 결과 조회·재시도하여 기존 성공을 복원하고 다시 차감하지 않는다.
9. 구매 전 총액·사용 재화·보유 상태를 표시하고 성공 후 지갑·소유품을 갱신한다. 기존 일괄 구매 모달을 재사용한다. 현금 충전과 재화 패키지 판매는 보류하고 무료 충전 경로를 만들지 않는다.
10. 완료: 개별 성공/실패, 일괄 전체 성공/한 품목 실패/두 재화 중 한 재화 부족, 커밋 전 오류와 커밋 후 응답 유실을 구분하여 검증한다. 일괄 구매의 골드+다이아 혼합 검증은 격리 fixture로 수행하며 운영 가격을 임의로 바꾸지 않는다. 이모티콘 클릭·조작된 구매 요청에서도 차감/지급이 없고, 실제 구매한 테두리·외형은 재로그인 후 보존된다.

**완료 기준**
