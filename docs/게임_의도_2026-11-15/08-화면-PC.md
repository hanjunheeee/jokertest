# PC 인게임 화면 — 의도와 지금 동작

PC 화면(`frontend/src/domains/game/ingame`)이 서버 알림을 받아 상태(store, 화면이 들고 있는 판 값)를 바꾸고 단계마다 무엇을 보여 주는지, 늦거나 순서가 바뀐 알림을 어떻게 막는지 적은 글.

- 경로 앞부분 줄임: `ig/` = `frontend/src/domains/game/ingame/`, `be/` = `backend/socket/gameSession/`
- 게임 규칙 자체는 02~05, 판 끝 뒤 이동은 06, 다시 붙기는 07, 모바일은 09에서 다룸

## 1. 흐름

### 1-1. 알림이 화면까지 오는 길
1. 인게임 화면이 뜨면 판 진행 알림 받기를 붙임. 연결·계정·신원 범위·다시 연결이 바뀔 때마다 새로 붙임 — `ig/hooks/useGameSessionSocketEvents.js:32-52`
2. 받는 알림 목록 17개 + 밤 차례 2개 — `ig/socket/session.js:6-36`
3. 손잡이(handler)마다 먼저 "붙일 때 범위가 지금도 같은지" 봄(연결 세대·소켓 id·계정·신원 세대·판·소속). 다르면 버림 — `ig/hooks/sessionEvents/scope.js:29-43`
4. 값 검사(파싱) → 스토어 액션 → 상태가 실제로 바뀐 때만 효과음 — `ig/hooks/sessionEvents/dayHandlers.js:15-26`
5. 스토어는 zustand 하나, 액션 묶음 다섯 개 — `ig/store/ingameStore.js:19-26`
6. 화면(`ig/pages/InGamePage.jsx`)은 스토어 값을 읽어 카드 판·시간 바·채팅·연출 창을 그림

### 1-3. 단계별로 보이는 것·누를 수 있는 것
1. **역할 공개(ROLE_REVEAL)**: 내 역할 창이 판마다 한 번 저절로 뜸, 10초 뒤나 첫 낮이 되면 저절로 닫힘 — `ig/hooks/useInGameRoleReveal.js:11`, `:38-59`, `:62-65`. 새로고침 뒤엔 다시 안 뜸(탭 저장소에 "봤음") — `:46`. 위 "내 역할 보기" 버튼으로 다시 열기(사람이 닫을 때까지) — `:76-81`. 시간 바 타이머 없음 — `ig/utils/timebar/phaseDeadline.js:5-28`
2. **낮(DAY)**: "낮이 되었습니다" 안내 창(확인 누를 때까지 판 조작 막힘) — `ig/hooks/useInGamePhaseEntrance.js:80-81`. 토론 중엔 시간 바 줄에 "준비" 버튼, 카드 메뉴 투표는 잠김("토론 중") — `ig/components/timebar/InGamePhaseActionRow.jsx:35-42`, `ig/utils/playerCardMenu.js:112-114`. 투표 중엔 남의 카드 좌클릭 → 투표/취소, 시간 바 줄에 "낮 집계" — `playerCardMenu.js:107-109`, `InGamePhaseActionRow.jsx:45-52`
3. **재판(TRIBUNAL)**: 재판 연출 창이 화면을 덮고 판 조작 막음 — `InGamePage.jsx:149-157`. 피고 카드 메뉴에 유죄·무죄 — `playerCardMenu.js:117-119`. 피고·죽은 사람은 표 못 냄 — `ig/utils/actionPanelLocks.js:60-71`
4. **밤(NIGHT)**: "밤이 되었습니다" 안내 → 그다음 밤 차례 안내("○○의 차례") — `ig/hooks/useInGameOverlayStack.js:14-20`. 내 역할 차례일 때만 카드 메뉴에 밤 행동 — `playerCardMenu.js:123-126`, `actionPanelLocks.js:35-42`. 의사만 자기 카드 고름 — `playerCardMenu.js:83-86`. 동료 광대 카드는 항목 없음 — `:65-67`
5. **밤 결과**: 본인 연출(죽임·살림·조사·확인 영상) → 개인 결과 창 → 다른 사람 연출 기다림 창(산 사람만 덮음) — `InGamePage.jsx:103-123`, `:247-260`
6. **판 끝(ENDED)**: 카드 메뉴 안 열림 — `playerCardMenu.js:96`. 결과 화면 이동은 06

### 1-4. 연출 창이 겹칠 때 순서
- 앞 것이 떠 있으면 뒤 것은 미룸(hold): 역할 공개 > 재판 추방 영상 > 단계 안내(낮·밤) > 밤 차례 안내 — `useInGameOverlayStack.js:14-20`, 시험 `frontend/tests/domains/game/ingame/hooks/useInGameOverlayStack.nightTurn.test.js:147`
- 밤 성공 연출은 역할 공개·추방 영상 뒤, 개인 결과 창은 성공 연출 뒤 — `InGamePage.jsx:103-109`
- 남 연출 기다림 창이 열리면 밤 차례 안내·단계 안내·역할 공개·개인 결과 창을 숨김 — `InGamePage.jsx:229-253`
- 죽은 사람 선택 창은 위 연출이 다 끝난 뒤에만 — `InGamePage.jsx:143-147`
- 스냅샷(서버에 다시 물어 받은 판 전체 값)으로 받은 단계·차례는 안내 창을 안 띄움(새로고침 때 안 뜨게) — `ig/utils/reduceInGamePhaseEntrance.js:27-32`

### 1-5. 남은 시간 막대(타이머)
1. 서버가 마감 시각(밀리초 시각 값)을 방송·스냅샷에 실음: 낮 `dayPhaseDeadline`, 밤 차례 `deadline`, 재판 `tribunalDeadline` — `be/phase/day.js:157-178`, `be/phase/night/turn.js:103-107`
2. 화면은 단계에 맞는 마감 하나만 고름 — `ig/utils/timebar/phaseDeadline.js:5-28`
3. 250ms마다 `마감 - 기기 지금 시각`으로 남은 초를 셈, 마감 지나면 멈춤 — `ig/hooks/timebar/useTurnProgress.js:17-52`
4. 게이지 전체 길이 = 마감 값을 처음 받은 순간의 남은 시간 — `useTurnProgress.js:20`
5. 서버 시각과 기기 시각 차이를 맞추는 장치 없음(점검 화면 `frontend/src/domains/maintenance/store/maintenanceStore.js:32-33`은 맞춤)

### 1-6. 채팅 칸 열림·닫힘
- 보낼 채널: 산 사람 낮·재판 = 낮 채널, 밤 = 내 직업 채널(시민도 시민 채널), 죽은 사람 = 낮·재판·밤 언제나 죽은 사람 채널 — `ig/utils/inGameChatChannel.js:42-51`
- 볼 채널: 죽은 사람은 죽은 사람 말 + 낮 말, 죽은 광대는 광대 밤 채팅도 읽기만 섞어 봄 — `inGameChatChannel.js:54-67`, `ig/components/chat/InGameChatSessionProvider.jsx:14-39`, `ig/utils/selfAlive.js:44-48`
- 서버 규칙과 같음 — `backend/game-core/chat/rules.js:38-71`
- 역할 공개·판 끝엔 보낼 채널 없음 → 입력칸은 열려 있고 보내기만 조용히 안 됨 — `ig/hooks/useInGameGameChatSession.js:141-143`, `ig/components/chat/InGameChatInput.jsx:139-152`
- 남 연출 기다림 창은 산 사람만 덮음 → 죽은 사람은 밤에도 채팅 — `selfAlive.js:28-30`, `InGamePage.jsx:122-123`
