### 1-2. 이번 규칙 (10줄)

1. **겉으로 보이는 결과만** 봄: 받은 알림 값, 돌려준 값·오류, DB에 남은 줄, 화면 글. 속 함수를 몇 번 불렀는지 안 봄.
2. **정답은 약속에서**: `결정.md` 등 출처 줄을 케이스마다 적음. 코드를 읽고 기대값을 만들지 않음, 옛 시험 기대값도 안 씀.
3. **판은 5~10명만**. 4명 이하 판을 차리는 시험 없음(거절을 확인하는 케이스만 예외).
4. **시간 규칙은 진짜 시간으로 적어도 하나**(5초·10초·60초·180초). 손잡이는 "앞 단계 빨리 가기"에만.
5. **"보임"은 진짜로**: 글자색·바탕 대비, 가려짐, 화면 안에 있나까지(3-6).
6. **두 번째도 봄**: 둘째 날 재판, 둘째 판, 같은 방 두 번째 판.
7. **사람마다 다른 선택**: 한 명은 "로비로", 나머지는 "대기방으로" 같은 섞인 순서.
8. **꼭 시험**: 분기·반복·입력 해석·돈·보안·접근성 — 경계값(하나 모자람·딱 맞음·하나 넘음)으로.
9. **실패할 수 있어야 함**: 코드가 이미 있어 "먼저 실패 보기"가 안 되므로 **망가뜨려 보기**로 실패를 한 번 봄(4-4).
10. **금지**: 가짜(mock)만 보는 시험, 속 구현 베끼기, 시간·순서 따라 흔들리는 시험, `skip`·`only`, 시험을 코드에 맞추기.

## 3. 브라우저 시험 3,000개

이 장은 간단·어려움의 뜻, 인게임 몫, 세는 법, 걸리는 시간, 진짜 시간과 손잡이 나누기, "보임" 확인법을 정함.

### 3-1. 간단·어려움 뜻 [안]

| 사람 | 브라우저 사람 1명 + 봇 4~9 | 브라우저 사람 2~5명 (+ 봇) |

### 3-2. 인게임 몫과 인원

- 인게임 = A02~A09: 1,860 / 3,000 = **62%** (간단 1,530 + 어려움 330).
- **모든 판은 5명 이상**. `table.setup`이 5명 미만이면 차리기 전에 오류 [사실, `e2e/helpers/game.js` 42줄]. 사람이 방장인 판(화면으로 만드는 판)도 5명 이상 모아서 시작.
- 7명 판 이상도 넣음: 버그 9는 7명 판, 직업 구성(6명 의사·8명 경비원·10명 마녀사냥꾼)은 6·8·10명 판 → 영역마다 인원 5·6·7·8·10명 판이 고루 나오게(목록 글에 인원 칸).
- 모바일 몫: 영역마다 약 25%(인게임은 30%) → 약 800개가 `mobile/` [안].

### 3-3. 세는 법 [안 — 8장 물음 1]

- 사실: 옛 목록은 모바일 케이스를 mobile·mobile-safari 두 번 셈(327 + 327), PC는 한 번 → 실행 2,554개 / 서로 다른 케이스 약 2,200.

  - 까닭: "3,000개"가 서로 다른 확인 3,000개여야 뜻이 있음. 사파리 전부(모바일 약 800개)를 다시 돌리면 시간이 약 1시간 늘어남.
  - 할 일: `e2e/playwright.config.js` mobile-safari 프로젝트에 `grep: /@safari/` (도우미 담당, 4-2).

### 4-4. 작업 폴더와 망가뜨려 보기 [안]

  - 반장이 묶음 자리 8개를 미리 만듦: `git worktree add <scratchpad>/wt/slot-1 HEAD` … `slot-8` (isolation 옵션은 원격 기본 브랜치에서 만들어질 수 있어 안 씀 — supervise 9장)
  - `node_modules`는 원본으로 잇기: `cmd /c mklink /J <slot>\backend\node_modules <저장소>\backend\node_modules` (backend·frontend·frontend-mobile·e2e·맨 위). 지울 땐 연결부터 뗌(`cmd /c rmdir`).
  - git에 안 올라간 환경값 파일 `backend/.env.testdb`·`e2e/.env.e2e`는 반장이 파일째 복사(값은 안 읽음).
  - **작업 폴더는 뒷정리 커밋 뒤에** 만듦(커밋 안 된 고침은 작업 폴더에 안 따라감).
- 에이전트는 자기 자리 폴더에서만 시험 파일을 쓰고, 끝나면 새 파일 목록을 넘김 → 반장이 저장소로 복사(새 파일뿐이라 안 겹침) → 자리는 다음 에이전트를 위해 비움(`git -C <slot> status`로 코드 바뀐 것 0 확인).
- 망가뜨려 보기 (자리 폴더 안에서만)
  1. 고칠 코드 파일을 옆에 복사(`x.js` → `x.js.orig`), 한 줄을 틀리게 바꿈(조건 뒤집기·값 하나 바꾸기·줄 빼기)
  2. 그 규칙을 보는 자기 시험을 돌려 **실패하는지** 봄
  3. 복사본으로 되돌리고(`mv x.js.orig x.js`) 다시 통과 확인
  4. 보고 표: 망가뜨린 곳(파일:줄) → 실패한 케이스 번호
  - 양: 영역 규칙(분기)마다 하나, 파일마다 최소 2번. 못 잡으면(망가뜨려도 통과) 그 시험을 고침.
  - 브라우저는 묶음마다 서버를 띄워야 해서 에이전트가 안 함 → 받은 버그 9개 케이스만 (다) 뒤 반장이 자리 폴더에서 고친 커밋을 되돌려(2-6 표) 실패를 봄.

- test-run 3장 표로 나눔: 진짜 버그 / 시험이 틀림(목록이나 코드가 출처와 다름 — 근거 줄) / 환경 / 모름.
- (나)의 "코드가 결정과 다름" 표와 합쳐 한 목록 → bug-fix로 영역별 에이전트(파일 안 겹치게)가 한꺼번에 고침.
- 고친 곳에 걸친 시험만 다시 → 마지막에 7-1 전체 한 번 더, 처음 숫자와 나란히.

### 7-3. 부하 (다 통과한 뒤)

- 명령(서버 1대, `준비_시험환경.md` 1-5): 서버 하나 켜 둔 뒤 `node scripts/loadtest/run.js --target <주소> --games 20 --players 5`, `--games 10 --players 10`
- 볼 것
  - **판 하나당 DB 질의 수**: 부하 앞뒤로 MySQL `SHOW GLOBAL STATUS LIKE 'Questions'` → 판 수로 나눔, 지난 기록(`docs/부하시험.md`)과 견줌. 이 값은 DB 서버 전체 셈이라 그동안 다른 시험·개발 서버를 안 돌림.
  - 새로 DB를 부르는 곳이 설계대로인지(`고치기_계획.md` 5-3): 판마다 골드 = 판 하나에 거래 하나, `game_settings` 읽기 0번, 탈주 대기 검사 0번, 로비 입장 정리 0번.
  - 오류 0, 접속 수 = 판 수 × 인원.
- 서버 2대(8장 물음 7): 지난번처럼 5명 50판 · 10명 30판, 오류·서버 옮기기 실패 0.
- 시간: 서버 1대 약 30분, 2대 약 40분 [짐작: 판 하나 3~4분, 판끼리 같이 돎].
- 출력은 파일로 받음(스크립트가 저장 안 함 [사실]).

### 7-4. 브라우저 한 번

- `cd e2e && npm run db:setup`(처음 한 번) → `bash tools/시험도구/with-lock.sh e2e bash tools/시험도구/br/all.sh` (단계: desktop → mobile → safari(@safari) → admin → @hard → serial → admin-phone-serial → 서버 2개 multinode → 서버 2개 serial)
- 시간: 3-4 표 약 8.5시간 (6.5~10시간).
- 실패만 한 번 다시(`br/run-phase.sh`가 실패 파일만 다시 함 [사실]) → 그래도 실패면 (라)처럼 나눔. 그 뒤 버그가 나오면 버그 목록과 걸친 코드의 시험만 다시.
- 받은 버그 9개 되돌려 보기(4-4 끝): 반장이 자리 폴더에서 2-6 커밋을 되돌린 채 그 케이스만 돌려 실패 확인 → 원래대로.

### 7-5. CPU 보기

- 돌리는 동안 뒤에서: `powershell -NoProfile -File tools/시험도구/cpu-watch.ps1` (30초마다 CPU·남은 메모리, 90% 넘거나 3GB 아래면 "부담 높음"과 많이 쓰는 프로그램 3개, 10분마다 요약) [사실]
- 브라우저 단계별 CPU는 `tools/시험도구/.run/br/cpu-<단계>.txt` [사실].
- 무거운 일은 한 번에 3개까지(`heavy.sh`), 시험 DB·브라우저 서버는 한 번에 하나(`with-lock.sh`).
- 에이전트를 띄우면 멈춤 감시를 같이 검(`node tools/시험도구/agent-watchdog.js <분> <자리 폴더…>`).
