# 시험 코드 쓰기 공통 규칙 (시험 쓰는 에이전트 모두 읽음)

이 글은 `시험_계획.md`의 부탁 글 틀(6-2 백·화·모, 6-3 브라우저)에 반장이 덧붙이고 바꾼 것을 적음. **계획 글과 이 글이 다르면 이 글이 맞음.**

## 계획 글에서 바뀐 것 (꼭)
1. **따로 만든 작업 폴더(worktree·slot)는 안 씀.** 저장소(`C:\Users\minsa\jokertest`)에서 바로 **새 시험 파일만** 씀. 계획 글의 `<slot>`·`<scratchpad>/wt/slot-n`은 전부 저장소 폴더로 읽음.
2. **"코드를 잠깐 망가뜨려 보기"는 하지 않음.** 다른 에이전트와 같은 코드를 보고 있어서, 코드 파일은 한 글자도 안 고침(잠깐이라도). 그 확인은 시험을 다 쓴 뒤 따로 한 단계로 함. 보고의 "망가뜨려 보기 표"는 안 씀.
   - 대신 시험이 **실패할 수 있는 시험**인지 스스로 따져 봄: 기대값을 일부러 틀리게 바꿔 한 번 돌려 실패하는지 보고 되돌림(내 시험 파일만 고치는 것이라 안전함). 파일마다 2번 이상, 무엇을 틀리게 해 봤는지 보고에 한 줄씩.
3. **브라우저 시험은 쓰는 동안 돌리지 않음**(사용자 말: 브라우저 테스트는 수정·부하 이후 한 번만). `npx playwright test --list <내 파일>`로 모이는지와 개수만 봄. `@smoke`를 묶음 끝에 돌린다는 계획 글의 말도 지금은 안 함.
4. 먼저 읽을 것에 **`docs/게임_의도_2026-11-15/시험_도우미.md`** 를 더함(도우미 쓰는 법·견본 파일·명령·손잡이·조심할 것 — 견본을 본보기로).

## 그대로인 것 (다시 적음 — 사용자 규칙)
- **테스트 케이스를 만들 땐 스킬을 꼭 읽음**(사용자: "무조건 필수"): `~/.claude/skills/design/references/tests.md`, `~/.claude/skills/test-run/SKILL.md`, `~/.claude/skills/bug-fix/SKILL.md`, `~/.claude/skills/comment/SKILL.md`.
- **정답은 목록 글(`시험목록/<영역>.md`)의 기대값 그대로.** 코드가 내놓는 값에 맞추지 않음. 목록이 틀려 보이면 고치지 말고 보고.
- **겉으로 보이는 결과만** 봄: 받은 알림·답·DB 줄·화면에 보이는 글. 함수가 몇 번 불렸는지·속 상태 칸은 안 봄.
- 판은 **5명 이상**(운영 규칙). 4명 이하는 "거절되는지" 확인할 때만. 판 인원은 목록 줄에 적힌 대로.
- **직업은 늘 정해 줌**(무작위로 두면 결과가 그때그때 바뀜). 시간은 가짜 시계로. 시간·순서에 따라 결과가 바뀌는 시험은 쓰지 않음.
- 표로 돌리는 시험(같은 틀에 값만 바꿈)은 **값 하나가 케이스 하나**가 되게(`test()`가 값마다 하나씩 생기게) — 목록 번호 범위와 개수가 같아야 함. **시험 이름에 목록 번호를 넣음**(예: `test('A03-B-001 5명 몰표면 재판', …)`).
- 자기 파일만 돌림. 전체 묶음(`npm test`)은 안 돌림. 명령은 `시험_도우미.md`와 `시험_계획.md` 4-5 표(폴더는 저장소로 읽음).
- **DB에 붙는 시험·Redis에 붙는 시험은 꼭 `tools/시험도구/with-lock.sh`로 한 줄 서서** 돌림(시험 DB 하나를 여럿이 같이 쓰면 서로 지움). 시험 DB는 정해진 시험용 DB만 — 다른 DB 이름이 보이면 멈추고 보고.
- 공용 도우미(`backend/tests/helpers/**`, `frontend/tests/helpers/**`, `frontend-mobile/tests/` 도우미, `e2e/helpers/**`, `e2e/tests/**/_*.js`·`roomHelpers`)는 **고치지 않음.** 필요한 것은 내 시험 파일 안에 작게 쓰고 보고에 "공용으로 올릴 것".
- **시험이 실패하면**: 먼저 시험 쪽(도우미 쓰는 법·준비 값·기다림)을 의심. 시험이 맞는데 코드가 다르면 **시험은 실패한 채로 둠**(`skip`·`only`·지우기 금지, 기대값을 코드에 맞추기 금지, 기다리는 시간만 늘려 덮기 금지). 코드는 안 고침. 보고의 "코드가 결정과 다름" 표에 적음.
- 금지: 코드 파일 고치기, 남의 시험 파일·목록 글 고치기, git으로 바꾸는 명령, `.env`·`.env.*` 값 읽기·출력, `npm install`, 서버를 4000번 포트에 띄우기, 포트 4100~4102·5273~5275 쓰기, Docker 켜고 끄기, `joker_realgame` DB, `frontend/tests/domains/game/ingame/store/participantDeparture.test.js` 건드리기, 비밀값·개인 정보·사용자 폴더 경로를 파일에 적기(공개 저장소).
- 주석: 사용자 말투(개조식 ~함/~음/~기, 쉬운 우리말, 이유만), 파일 머리 2줄(무슨 시험인지·어느 목록 번호인지).
