# 모바일 화면(판 중) — 의도와 지금 동작

모바일 앱(`frontend-mobile`)은 판 진행 로직을 PC 코드에서 그대로 빌려 쓰고 화면만 따로 그림. 폰 세로는 카톡형 대화 화면, 폰 가로·태블릿은 예전 칸 배치. 이 글은 "모바일이 PC와 같은 의도로 도는가, 어디가 다른가"를 적음.

- 줄임: `mo:` = `frontend-mobile/src/`, `fe:` = `frontend/src/`, `ig` = `domains/game/ingame`
- 옛 설계 문서(`docs/모바일-인게임-카톡형/기획.md·스토리.md·설계.md·경계.md`, `docs/모바일-광고/기획.md`)는 커밋 5eaa7dd5에서 지워짐 → `git show 5eaa7dd5^:<경로>`로 읽음. 남은 문서: 같은 폴더 `결정.md`·`테스트.md`, `docs/모바일-광고/결정.md`·`설정.md`

## 0. 모바일이 PC 코드를 어디까지 같이 쓰나

빌드 설정 `frontend-mobile/vite.config.js:17-22`
- `@` → `../frontend/src` (PC 로직), `@m` → `./src` (모바일 화면)
- 그림·소리·영상 폴더도 PC 것을 그대로 씀(`publicDir`, vite.config.js:14) — 304MB 두 벌 안 두기
- React·zustand·socket.io 등은 한 벌로 묶음(`dedupe`, vite.config.js:24) — 두 벌이면 스토어가 갈라져 훅 오류

## 1. 흐름

### 1-1. 화면 고르기
1. `/ingame` 들어옴 → 판 번호·상태가 맞지 않으면 빈 화면, 스냅샷 확인 끝났는데 판이 없으면 `/multiplay`로 (`useInGamePage.js:38-44`, PC와 같은 함수)
2. 화면 모양: `useWideChat`이 "폰 가로(높이 540 이하·폭 560 이상) 또는 폭 48rem(768px) 이상"이면 넓은 배치, 아니면 카톡형 (`mo:ig/hooks/chat/useWideChat.js:5`, `InGamePage.jsx:86,101-102`)
   - 폰 세로 → `TalkLayout` (위 줄 + 단계 줄 → 펼친 진행 바 → 초상 띠 → 채팅방 → 행동 줄, 입력칸은 화면 바닥 자리) `TalkLayout.jsx:30-69`
   - 폰 가로·태블릿 → 예전 칸 배치(위 줄·진행 바·카드 판·채팅·행동 줄) `InGamePage.jsx:24-79`
   - 돌리면 바로 바뀜(matchMedia 구독). 이모티콘 기록은 배치와 상관없이 늘 쌓음 → 가로일 때 온 것도 세로 채팅방에 남음 (`InGamePage.jsx:87-88`)
3. 연출·창은 전부 `OverlayLayer`가 body로 꺼내 띄움(화면 틀이 container라 fixed가 갇혀서) `OverlayLayer.jsx:15-19`

### 1-3. 투표·밤 행동 고르는 방법
1. 초상 띠(참가자 작은 카드 한 줄, 옆으로 넘김) 칸을 탭 → PC 카드 메뉴 훅이 항목을 줌 → 아래서 올라오는 시트에 버튼 (`PortraitStrip.jsx:45-61`, `useCardSheet.js:6-10`)
2. 항목 없는 카드(토론 중 내 칸 등)는 시트가 안 뜸 (`useCardSheet.js:5`, 시험 `talk-strip.spec.js:103,146`)
3. 고른 대상 칸은 강조 (`PortraitStrip.jsx:47-48`) — 밤 대상 강조가 다음 날까지 남는 문제는 PC와 같은 훅(→ 03·04에서 다룸, `docs/known-issues.md:258`)
4. 띠 끝 "크게" 단추 → 띠 대신 PC형 카드 판(높이 46svh까지, 안에서 스크롤). 펼친 판 카드도 같은 시트 (`PortraitStrip.jsx:22,71-83`)
5. 단계·날짜·차례·조작 막힘이 바뀌면 시트 저절로 닫힘(PC 훅) `fe:ig/hooks/useInGamePlayerCardMenu.js:158-169`
6. 이모티콘: 내 칸 0.45초 길게 누르기(안드로이드 길게 누르기·우클릭은 contextmenu) → 팔레트. PC는 우클릭 (`useLongPress.js:5`, `StripSlot.jsx:36-40`)

### 1-4. 남은 시간 표시
- 단계 줄: 1초마다 셈, 마감 지나면 멈춤. 마감 없으면 시간 칸 비우고 단계 이름만 (`usePhaseClock.js:17-29`, `PhaseLine.jsx:28-29,43-47`)
- 진행 바: 단계 줄 누르면 펼침. 펼친 순간 게이지가 틀리지 않게 늘 그려 두고 숨기기만 (`TalkLayout.jsx:47-50`), 값은 PC `useTurnProgress`(250ms)
- 시간 계산은 `Date.now()`와 서버 마감 시각의 차이 → 화면을 껐다 켜도 돌아오면 바로 맞는 남은 시간(짐작 아님: 매 셈마다 지금 시각으로 다시 계산 `usePhaseClock.js:22-24`)

### 1-5. 죽은 사람 화면
1. 처형·암살로 죽음 → 앞 연출이 끝난 뒤 "사망 후 선택" 창(관전 계속하기·게임 나가기, 실패면 다시 시도·결과 확인) (`useDeadChoice.js:38-57`, `DeadChoiceOverlay.jsx`)
2. 관전 계속 → 채팅방 위 "죽은 사람끼리" 회색 띠, 내 말·죽은 사람 말은 회색 말풍선, 산 사람 낮 말도 같이 봄 (`TalkList.jsx:51`, `buildTalkFeed.js:10`, 시험 `talk-dead.spec.js:53-109`)
3. 초상 띠·채팅 초상 흐리게, 칸 이름에 "사망" (`TalkAvatar.jsx:8-11`, `slotLabel.js:5`)
4. 밤 대기 창이 죽은 사람은 안 덮음 → 밤에도 죽은 사람끼리 말함 (`useOverlayLayer.js:76-77`, 결정 `docs/버그수정_결정_2026-11-09.md:163`)
5. 투표·기권·이모티콘은 꺼짐(PC 훅 조건) 시험 `talk-dead.spec.js:122-137`

### 1-6. 채팅 칸 여닫힘
- 폰 세로: 채팅방이 화면 대부분. 재판 중엔 `invisible`로 숨기기만 → 그사이 생긴 처형 알림이 안 날아감 (`TalkLayout.jsx:54-58`, 결정.md "재판 중 채팅방은 빼지 않고 숨기기만")
- 맨 아래 보던 중이면 새 줄 따라 내려감, 위로 올려 읽는 중이면 그대로 + "새 메시지 ↓" 단추 (`useStickToBottom.js:20-28`, `TalkList.jsx:71-75`)
- 보내기 실패·전송 중은 입력칸 위 한 줄 (`TalkList.jsx:31-40`)
- 폰 가로·태블릿: 채팅 틀 빈 곳 누르면 "크게 보기" 창(틀 한 장 큰 글씨 + 입력) `ChatPanel.jsx:31-35`, 재판 뜨면 닫힘 `ChatPanel.jsx:23-27`
- 채팅방 한 줄 목록 = 채팅 세션 말 + 시스템 알림 + 받은 이모티콘을 시각 순으로 섞음 (`buildTalkFeed.js:24-57`)
  - 시스템 알림은 서버가 안 보내서 화면이 명단 변화(살았다→죽음, 연결됨→끊김)를 보고 만듦 (`useSystemNotices.js:1-3`, `playerNotices.js:35-56`)
  - 처음 들어올 때는 알림 안 만듦 (`playerNotices.js:42-44`)
  - 알림·이모티콘 기록은 화면 밖 저장소(판 단위, 최근 40줄) → 화면 돌림·재판으로 다시 그려도 남음 (`talkHistory.store.js:1-17`)

### 1-7. 장면 전환·연출
- 연출은 PC와 같은 훅·같은 순서·같은 미루기(앞 연출이 있으면 뒤 연출 hold) `useOverlayLayer.js:52-86`
- 연출이 덮는 동안 화면 잠금(`surfaceLocked` → 카톡형 화면 `inert`) — 연출이 뜨는 첫 그림부터 잠기게 그리기 전에 값 넘김 (`useOverlayLayer.js:41-44`, `TalkLayout.jsx:31-33`)
- 바닥 입력칸은 화면 틀 바닥 자리로 portal돼 `inert` 밖이라 `locked`로 따로 막음 (`Composer.jsx:14,55`)
- 움직임 줄이기 설정이면 재판 처음 단계 건너뜀 (`useTribunalIntro.js:7-19`)
- 그리는 z 순서: 역할 공개·재판 55, 단계 입장·밤 차례 60, 밤 결과·밤 대기 65, 사망 선택 68, 추방 70 (`fe:ig/constants/parchment/ingameParchmentModalVariants.js:40,54,69,99`, `TribunalOverlay.jsx:68`, `DeadChoiceOverlay.jsx:50`, `ExpulsionOverlay.jsx:13`)

### 1-8. 화면을 껐다 켜거나 다른 앱 다녀올 때
- 모바일 인게임엔 화면 숨김(`visibilitychange`) 전용 처리 없음 — `mo:` 전체에서 못 찾음
- 소켓이 끊겼다 다시 붙으면 PC 공용 훅이 "다시 연결" 횟수를 올리고 스냅샷을 다시 묶음 (`fe:ig/hooks/sessionEvents/useSessionConnection.js:1-3,9-16`) → 07에서 다룸
- 시간은 지금 시각으로 다시 셈(1-4), 광고 5초 셈도 시작 시각과의 차이(`interstitialRule.js:27-30`)
- 새로고침: 낮 말은 다시 보임(서버가 줌), 시스템 알림·이모티콘 줄은 사라짐(Q09-2)

### 1-9. 키보드가 올라올 때
- 안드로이드: `interactive-widget=resizes-content`로 화면 높이가 줄어 입력칸이 안 가려짐 (`frontend-mobile/index.html:6-9`)
- iOS: 화면 높이가 안 줄어 → 입력 줄을 가려진 만큼 위로 올리고(`useKeyboardLift.js:15-23`), 채팅방 아래를 그만큼 비움(`TalkLayout.jsx:51-56`), 재판 연출 아래도 비움(`TribunalOverlay.jsx:33-42`)
- 보이는 높이가 600px 아래에서 입력 중이면 초상 띠·진행 바를 잠깐 접어 채팅방 자리 냄, 키보드 내리면 다시 보임 (`useCompactTyping.js:5-6,26`, `TalkLayout.jsx:47,51`). 폰 가로는 판을 접지 않음 (`InGamePage.jsx:38-41`)

### 1-10. 광고가 끼는 자리와 때
- 하단 배너: 허용 목록 화면만(로비·모드·방 목록·방 만들기·대기방·마이페이지·상점·서고·설정·결과). 인게임·로그인 없음 (`bannerRoutes.js:5-19`, `MobileShell.jsx:24`)
- 한 판 끝 광고: 결과 화면 첫 연출이 끝나고(`stage === "result"`) 1.5초 뒤, 판마다 한 번(판 번호를 열 때 바로 기억) (`useInterstitialAd.js:36-43`, `interstitialRule.js:5-8,18-23`)
  - 5초 동안 뒤 화면 막·Esc·뒤로 가기 다 막힘, 5초 뒤 닫기 (`InterstitialAd.jsx:40-81`, `useBackClose.js:21-44`)
  - 광고 없음·스크립트 실패면 창 바로 닫힘 (`InterstitialAd.jsx:68`, `AdSlot.jsx:34-57`)
- 판 흐름을 막나: 판 진행 화면엔 광고가 없어 안 막음. 결과 화면에서 "대기방으로"·"로비로"를 최대 약 6.5초(1.5 + 5) 늦출 수 있음. 1.5초 안에 버튼을 눌러 화면을 떠나면 타이머가 풀려 안 뜸(`useInterstitialAd.js:42`). 결과 화면엔 시간 맞춰 자동으로 옮기는 동작이 없음(`fe:domains/game/result/hooks/*` 에 자동 이동 타이머 없음, 읽은 범위) → 광고가 놓치게 하는 일은 없다고 봄(짐작)
- 이유(결정 `docs/모바일-광고/결정.md` 5장): 버튼 누를 때 광고를 띄우면 같은 손가락으로 광고를 잘못 누르기 쉬움(정책 위반), 대기방 복귀는 같은 방 사람들과 같이 하는 동작이라 늦추면 안 됨
- 공급자 설정이 없으면 운영 빌드엔 광고 자리 자체가 없음, 개발 서버는 회색 상자 (`adConfig.js:38-41`)
