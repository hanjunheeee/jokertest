# 사용자가 받은 버그·수정 요청 목록 (2026-11-16)

플레이한 사람들이 알려 준 것. 사용자가 그대로 전달함.

1. 프로필 설정을 눌렀을 때 계정관리로 바로 들어감
2. 구매가 안 될 때 문구가 안 보임
3. 게임이 끝나고 "대기방으로"를 안 누르고 "로비로"를 누른 사람이 있고 나머지는 "대기방으로"를 누른 경우: "로비" 누른 사람은 게임 참여가 안 되고, 대기방에 들어간 사람들도 남아 있는 세션 문제로 게임 시작이 안 됨
4. 방을 만들고 나서 중복 접속하면 그 전 세션이 남아 있음(방이 사라지지 않음)
5. 광대가 밤에 암살하면 암살당하는 사람과 광대만 영상이 뜸. 나머지는 "진행중입니다"라고 뜸 (다 같이 떠야 할지 말지)
6. 방을 만들었던 사람이 게임이 끝난 뒤 → 대기방 → 게임 삭제 → 게임 다시 만들기를 하면 전 세션이 남아 있음. 같이 참여했던 사람들도 방이 갑자기 생성됨. 그래서 로비로 나갔던 사람은 결국 어느 방에도 접속 불가
7. 추방 기능이 활성화되지 않음
8. 두 번째 날 투표 진행 때 무죄/유죄 오류: 한 사람이 무죄·유죄 선택이 안 되고 시간이 지나야 넘어감
9. 기권이 다수인데도 한 명이 투표하면 피고인으로 넘어감 (어떻게 할지)
