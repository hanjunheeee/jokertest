# 시험을 쓰다 나온 코드 문제 — 모아서 한꺼번에 고칠 목록

## 공용 도우미에 올릴 것 (시험을 한 번 돌린 뒤)

- `assertNoForbiddenPrivateData`: 값이 `null`인 `role` 칸(`phase_settle_started`)과 밤 결과 방송의 `deathReveals.*.source`를 샌 것으로 잡음 → 허락 경로 넣기
- 판 두 개를 한 번에 다루기: `gf.socketWorld`가 부를 때마다 접속 목록을 갈아 끼움
- 가짜 시계: node 가짜 시계는 한 번에 넘긴 시간의 끝 시각으로 타이머를 부름 → 시각 경계는 1초씩 넘김(`시험_도우미.md`에 한 줄)
- 영역마다 따로 만든 것: 하루 넘기기(`passDay`·`passNight`·`executeDay`), 밤 차례 돌리기(`playNight`·`skipToTurn`), 끊김·다시 붙기, 대기방→시작(`makeWorld`), DB용 판 열기, 5~10명 방 만들기
- 판 골드 지급을 가짜로 바꾸는 손잡이(`__setGameGoldGrantForTests`)가 `services/game/record/index.js`에서 안 나옴 → 시험이 `persist.js`를 바로 부름
