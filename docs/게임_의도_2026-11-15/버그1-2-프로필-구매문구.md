# 버그 1·2 — 프로필 설정이 계정관리로 감 / 구매 실패 문구가 안 보임

한 줄 요약: 버그 1은 로비 프로필 배너의 톱니(이름 "계정 설정")가 계정 관리로 곧장 가는 것이고, 꾸미기로 가는 로비 단추는 10/20 화면 갱신 때 빠졌음. 버그 2는 코드상 거의 모든 실패에 글이 있지만, 글이 구매 단추와 멀리(판 맨 위) 뜨고 PC 화면에서 잔액 부족 글을 확인한 시험이 없음. 실제로 글이 안 뜨는 길은 몇 개뿐임.

- 읽기만 한 조사. 코드·시험은 안 고침. 서버·브라우저·시험 묶음 안 돌림
- 줄임: `fe` = `frontend/src`, `fm` = `frontend-mobile/src`, `be` = `backend`
- [사실] = 코드·시험에서 직접 봄, [짐작] = 코드로 미루어 생각함

### 글이 안 뜨는 길 (다시 겪는 차례를 가장 짧게)

코드상 "아무 글도 없는" 길은 적음. 플레이한 사람이 본 것은 아래 1번(글이 멀리 떠서 못 봄)일 가능성이 가장 큼 [짐작].

1. **글이 구매 단추에서 멀리, 판 맨 위에 뜸** (PC·모바일 둘 다) [사실: 자리 / 짐작: 못 봤을 것]
   - 차례: 골드 0인 계정 → 상점 → 스킨 하나 고름 → 오른쪽 아래 "구매" 누름 → 단추는 다시 켜지기만 하고, 글은 판 맨 위 작은 갈색 상자에 뜸
   - PC는 판 위쪽에 틀 그림 장식 자리가 있어(`constants/storeLayoutStyle.js:8-21`의 위 여백) 상자가 장식 위에 겹칠 수 있음 — 브라우저로 확인 못 함
   - PC 화면에서 "잔액 부족" 글을 확인하는 시험 없음. 모바일만 있음(`e2e/tests/mobile/screens-store.spec.js:33`). PC e2e `store/single-purchase.spec.js:66`은 서버 답만 봄
2. **충전 실패 주소로 돌아왔는데 다른 진행 중 주문이 화면에 떠 있음**
   - 차례: 결제 대기 중인 주문이 남은 계정 → 상점 들어가면 그 주문 확인이 돎 → 새 충전 → 결제창에서 실패 → `/store?topup=fail`로 돌아옴 → 실패 안내 없음
   - 근거: `paymentReturn.js:200` "다른 주문이 보이는 중이면 실패·잘못된 주소 안내는 띄우지 않음"
3. **로그인 풀림(401)**: 구매 누름 → 상점 글 없이 로그인 처리로 넘어감 — `response.js:43-45`
