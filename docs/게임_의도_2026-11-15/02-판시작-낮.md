# 판 시작~낮 끝 — 의도와 지금 동작

방장 시작이 받아들여진 뒤 판이 만들어지고(직업·색·자리), 역할 공개 10초를 지나, 첫 낮의 토론·투표가 재판 또는 밤으로 넘어가기까지를 적음.

- 시작 요청 검사(인원·준비·방 설정) → 01에서 다룸
- 재판 → 03, 밤 → 04, 승패 → 05, 끊김·나가기 → 07, 화면 자세한 것 → 08·09, 개발 전용 규칙 → 10
- 기준은 운영 규칙(`NODE_ENV=production`)

## 1. 흐름

## 4. 의도가 갈리는 곳 (사용자가 고름)

### Q02-1. 한 표만 있어도 재판에 올라감
- 무엇이 갈리나: 서버는 진짜 표 중 최다 1명이면 기권 수와 상관없이 재판. 화면 주석은 "기권보다 표가 많음"이라 적었는데, 실제 검사는 "산 사람 수 > 기권 수"(= 진짜 표 1개 이상)라 서버와 같게 돔
- 어디: `game-core/phase/day/ballots.js:28-36`, `:66-73` / `frontend/src/domains/game/ingame/utils/dayVoteResolve.js:50-54` / 결정 문서 규칙 3 `:102` "최다 1명이면 재판"
- 겪는 모습: 7명 중 1명만 A를 찍고 6명이 기권해도 A가 재판에 섬
- 안
  - 안 1(추천): 지금대로 — 결정 문서 글자 그대로이고 재판에서 다시 유죄·무죄를 가름
  - 안 2: 진짜 표가 기권보다 많을 때만 재판, 아니면 밤
  - 안 3: 최소 득표(예: 2표) 이상일 때만 재판

### Q02-2. 다 냈는데 저절로 집계 안 함 + 누구나 집계 버튼
- 무엇이 갈리나: 산 사람이 다 내도 서버가 저절로 판정 안 함. "낮 집계" 버튼을 누군가 눌러야 하고, 버튼은 죽은 사람 화면에도 켜짐(서버도 판 사람이면 받음). 토론은 "모두 준비하면 바로 넘어감"인데 투표는 아님
- 어디: `day/resolve.js:19`(`requireActor: false`), `:38-41` / `handlers/dayVote.js:97-149` / 화면 `frontend/src/domains/game/ingame/hooks/useInGameActionPanel.js:78-86`, 모바일 `frontend-mobile/src/domains/game/ingame/hooks/actions/buildRowActions.js:72`
