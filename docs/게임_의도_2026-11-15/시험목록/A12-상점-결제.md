# A12 상점·결제·재화 — 시험 케이스 목록

이 글은 상점 구매·골드 구매·다이아 충전(토스)·지갑과 장부·쿠폰·끼우기·이모티콘 팔레트·거래 내역·구매 실패 글(버그 2)에서 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 400 · 화 150 · 모 13 · 브 간단 110 + 어려움 10 = 683).

- 번호: A12-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
- 종류: 순수 / 요청(HTTP 요청 흐름) / DB / 화면 상태 / 화면 부품 / 브
- 인원: 이 영역은 판을 안 차림 → "N명 판" 대신 계정·창 수를 적음. 판 보상(`GAME_REWARD`) 줄은 판을 돌리지 않고 장부에 넣어 둔 계정으로 봄(판 끝 지급 자체는 A07)
- 표 돌리기는 번호 범위 한 줄 + "값" 목록 (값 하나 = 케이스 하나)
- [버그 2] = 받은 버그 다시 생기는지 잡는 케이스, [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀
- **돈이 걸린 곳**이라 잔액은 늘 경계값(0·하나 모자람·딱 맞음·하나 남음)으로, 거절이면 "지갑·장부·가진 것·구매 요청 네 표가 하나도 안 바뀜"까지 봄
- 결제사(토스)는 늘 가짜: 백은 `backend/tests/helpers/fakeTossAdapter.js`(결과 시나리오 10가지 `SCENARIOS`)·`fakeTopupDb.js`, 브는 가짜 승인 서버 `e2e/tests/store/fakeToss.js`(결제 키 앞말 `pk_ok_`·`pk_reject_`·`pk_slow_`로 답 고름). **키·비밀값·진짜 결제 번호는 이 글과 시험에 안 적음** — 키 모양 시험은 "앞말만 맞는 지어낸 값"을 시험 안에서 만듦
