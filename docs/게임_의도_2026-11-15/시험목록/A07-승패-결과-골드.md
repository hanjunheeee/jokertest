# A07 승패·결과·판마다 골드 — 시험 케이스 목록

이 글은 승패 판정·판 끝 직업 공개·결과판·전적 저장·판마다 골드·업적·통계에서 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 300 · 화 100 · 모 8 · 브 간단 140 + 어려움 40 = 588).

- 번호: A07-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
- 종류: 순수 / 흐름 / 요청 / DB / Redis / 화면 상태 / 화면 부품 / 브
- 인원: 판을 차리면 "(N명 판)"으로 적음. 백 판 도우미·브 `table.setup` 모두 5명 이상
- 표 돌리기는 번호 범위 한 줄 + "값" 목록 (값 하나 = 케이스 하나)
- [버그 n] = 받은 버그 다시 생기는지 잡는 케이스, [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀
- 출처 줄임: `결정` = 결정.md, `[임시 n]` = 결정.md 맨 아래 "반장이 임시로 정한 것" n번, `고치기` = 고치기_계획.md, `05` = 05-승패-결과.md(구간 글, 고치기 **전** 흐름 — 결정과 다르면 결정)
- 돈이 걸린 곳(판 골드·지갑·장부·관리자 값)은 경계값(하나 모자람·딱 맞음·하나 넘음)과 받는 사람 갈래를 다 나눔
- 코드에서 찾은 이름 (정답 아님, 찾기용)
  - 승패 판정 `evaluateWinCondition`(`backend/game-core/core/rules/terminal.js`), 끝난 판 거절 코드 `GAME_ALREADY_ENDED`
  - 판 끝 칸 `winResult = { winner, reveals[] }`, 사람마다 `reveals[i].{uuid,nickname,role,team,alive,deathReason,goldReward}` (`backend/game-core/result/winReveal.js`)
  - 판 끝 방송 사건: 밤 `night_result_applied`(밤 결과), 재판 `tribunal_vote_resolved`(재판 결과), 나감·60초 탈락 `player_eliminated`(탈락 알림), 저장 뒤 `account_cache_invalidated`(계정 값 다시 읽어라), 업적 `achievement_granted`(업적 받음)
  - 판 골드: 판 시작 때 `session.goldReward`(`socket/matchmaking/room/startLaunch.js`), 받을 몫 `resolveGameGoldReward`·묶음 `buildGameGoldGrant`(`game-core/result/record.js`), 지급 `grantGameRewards`(`services/economy/grants.js`), 장부 사유 `GAME_REWARD`, 참조 id(같은 일 두 번 막는 이름표) `game-reward:<gameId>`
  - 값 저장 표 `game_settings` 줄 `GAME_GOLD_REWARD`(처음 1), 메모리 값 `services/ops/gameSettings.js`(범위 0~100), 다시 읽기 `reloadSync`(서버끼리 다시 읽기 알림)
  - 관리자 API(관리자 요청 길) `GET/PUT /admin-api/game-settings` 몸 `{ goldReward }`, 거절 `400 INVALID_INPUT` + `details.field`, 감사 기록(관리자 한 일 기록) 이름 `GAME_SETTING_UPDATE`(화면 글 "판 골드 바꿈")
  - 결과판 골드 글 `formatGoldRewardLabel` → "+1골드", 표시 칸 `data-testid="game-result-gold-reward"` (PC `GameResultPlayerRow.jsx`, 모바일 `players/PlayerRow.jsx`)
  - 시험 손잡이: 백 `__setGoldRewardForTests`·`__setGameGoldGrantForTests`, 브 `/e2e/games/:gameId/advance`·`/expire-graces`(60초 바로 끝내기)
- 주의: `NODE_ENV=test`면 판 출처가 `test`라 업적 보상이 안 붙음 → 업적 DB 시험은 `GAME_SOURCE_OVERRIDE=production`처럼 출처를 운영으로 둬야 함 (코드 `record.js`, 찾기용)
