# A13 친구·알림·초대 — 시험 케이스 목록

이 글은 친구 신청·친구 목록·즐겨찾기·차단·접속 표시·게임 초대(보내기·받기·답)·알림·신고 보내기·사람 카드 메뉴·문의에서 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 200 · 화 110 · 모 6 · 브 간단 100 + 어려움 10, 합 426).

- 번호: A13-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리. 백은 순수 001~020 · 흐름·요청 101~170 · DB 301~410, 화는 상태 001~058 · 부품 201~252, 브 간단은 PC 001~070 · 모바일 071~100.
- 종류: 순수 / 흐름 / 요청 / DB / 화면 상태 / 화면 부품 / 브. "요청"은 서버 앱에 HTTP 요청을 보내 답(상태·글)만 보는 것(시험 DB는 씀), "DB"는 DB 줄까지 보는 것.
- 백 종류 나눔: 계획 2-5는 순수 20 · 흐름 80 · DB 100인데, 친구·초대 규칙이 거의 DB에서 갈려 순수 20 · 흐름·요청 70 · DB 110으로 씀(합 200 같음).
- 인원: 판을 차리는 줄은 "(n명 판)"(5~10), 대기방은 "(정원 n · 지금 m명)". 친구·알림만 보는 줄은 판이 없어 인원 칸 없음.
- 표 돌리기는 번호 범위 한 줄 + "값" 칸에 값 목록 (값 하나 = 케이스 하나)
- [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀. 받은 버그 9개(시험_계획 2-6)는 이 영역에 없음.
- 사건(event, 서버와 화면이 주고받는 알림) 이름·경로·오류 글·칸 이름은 지금 코드(커밋 `f0b94266`)에서 찾음. 기대값은 아래 출처에서만 가져옴.
- 브 "보임"은 `expectReadable`(보임·화면 안·안 가려짐·글자 대비 4.5 이상 확인 도우미, `e2e/helpers/visible.js`, 시험_계획 3-6)로 봄.
- 브 친구 맺기는 `e2e/helpers/friends.js`(`sendRequest`·`makeFriends`·`botApi`)로 앞 단계를 빨리 함. 확인하려는 단계는 화면으로 누름.
- 개인 정보·진짜 메일 주소는 안 씀. 계정은 시험 계정·봇만.
