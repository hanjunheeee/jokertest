# A08 판 끝 뒤 같은 방 — 시험 케이스 목록

이 글은 판이 끝난 뒤 결과 화면 → "대기방으로"·"로비로" → 같은 코드 대기방 → 다음 판까지 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 220 · 화 60 · 모 8 · 브 간단 100 + 어려움 50 = 438).

- 플레이한 사람들이 버그를 가장 많이 겪은 구간(받은 버그 3·6)이라 사람마다 다른 단추 순서를 많이 넣음.
- 번호: A08-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
- 종류: 순수 / 흐름 / 요청 / DB / 화면 상태 / 화면 부품 / 브
- 인원: 판을 차리면 "(N명 판)"으로 적음. 백 판 도우미·브 `table.setup`(판 차리기 도우미) 모두 5명 이상
- 표 돌리기는 번호 범위 한 줄 + "값" 목록 (값 하나 = 케이스 하나)
- [버그 n] = 받은 버그 다시 생기는지 잡는 케이스, [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀
- 출처 줄임
  - `결정` = 결정.md 줄 이름, `[임시 n]` = 결정.md 맨 아래 "반장이 임시로 정한 것" n번
  - `고치기 16` = 고치기_계획.md 단위 16 "시험 단계가 꼭 넣을 케이스", `고치기 2-1` = 같은 글 2-1 설계 안, `고치기 14·17` 같음
  - `06` = 06-판끝-대기방-로비.md(구간 글, 고치기 **전** 흐름 — 방장이 새 방을 만들고 자동 입장 → 결정과 다르면 결정), `00 B06-n` = 00-버그-다시확인.md
  - `화면 문구` = 화면에 적힌 사용자 글(출처 ⑤, 시험_계획 2-5)
- 시간 규칙: 180초를 **확인하는** 케이스는 백은 가짜 시계, 브는 진짜로 기다림(`@realtime`, H-031~040). 그 밖 브 케이스는 시험 손잡이 `closeResults`(결과 바로 닫기)로 넘김 (시험_계획 3-5)
- 코드에서 찾은 이름 (정답 아님, 찾기용)
  - 화면→서버 "대기방으로" 사건 `return_to_room { gameId }`, 답 `{ ok:true, room }` / `{ ok:false, code, message }` — `backend/socket/matchmaking/room/returnRoom.js`
  - 판 끝 방 다시 열기 `reopenRoomAfterGame`, 180초 끝 정리 `closeReturnHold`, 방장 자리 칸 `room.returnHold.reservedHostUuid`(남겨 둔 방장), 방 내용 칸 `reservedHostUuid`
  - 180초 시계 `scheduleEndedSweep`(판 끝 정리 예약) — `backend/socket/gameSession/departure/end.js`, 값 `RESULT_SCREEN_MS = 180 * 1000`·`getResultClosesAt` — `backend/game-core/queries/ended.js`
  - 서버→결과 화면 사람 `game_result_closed { gameId, reason:'RESULT_TIMEOUT' }`, 판 끝 칸·스냅샷(판 상태 다시 받기) 칸 `resultClosesAt`(결과 화면 닫힘 시각)
  - 판 끝 칸이 실리는 사건: `night_result_applied`(밤 결과), `tribunal_vote_resolved`(재판 결과), `player_eliminated`(탈락 알림)
  - 방장 바뀜 알림 `host_changed { hostUuid, reservedHostUuid, canStart }`, 들어옴 알림 `player_joined_room`
  - 판 시작 때 방 정보 옮겨 담기 `session.returnRoomSource`(코드·설정·추방 횟수 `kickCounts`) — `room/startLaunch.js`, 추방 3번 `KICKED_TOO_MANY_TIMES` — `room/kickLimit.js`
  - 거절 코드 `ROOM_ALREADY_STARTED`("이미 게임이 시작된 방입니다."), `ROOM_FULL`, `SESSION_ENDED`, `ROOM_NOT_FOUND`, `ROOM_CODE_MISMATCH`("입장 코드와 일치하는 방이 없습니다."), `NODE_DRAINING`, `DESERTION_COOLDOWN`(탈주 대기) — `backend/socket/roomJoinErrors.js`, `join/guards.js`, `join/joinChecks.js`
  - 공개 방 목록 `buildPublicRoomList`(0명 방 뺌) — `room/view.js`, 정원 자리 셈 `reservedSeatsFor` — `join/joinRecheck.js`
  - 로비로: `leave_game_session`(끝난 판 나가기), 로비 입장 정리 `enter_lobby` — `room/lobbyEntry.js`
  - 지운 사건: `get_party_matching_room`(화면→서버), `party_matching_room_ready`(서버→화면)
  - 시험 손잡이(시험 전용 서버 길): `POST /e2e/games/:gameId/close-results` → 브 `internal.closeResults(gameId)`, 60초 끊김 `internal.expireGraces(gameId)` — `backend/routes/e2e.routes.js`, `e2e/helpers/internal.js`
  - PC 화면: 결과 화면 `frontend/src/domains/game/result/page/GameResultPage.jsx`, 훅 `useGameResultReturnToMatching`·`useGameResultCloseTimer`·`useResultSecondsLeft`, 남은 초 계산 `computeResultSecondsLeft` — `result/socket/resultClose.js`, 표시 `data-testid="result-close-timer"`·`data-seconds-left`, 실패 안내 `data-testid="result-leave-notice"`·`data-notice-source`
  - 로비로 확인 글 `EXIT_CONFIRM_MESSAGES.RESULT`·실패 글 `selectResultExitFailureNotice` — `frontend/src/domains/game/ingame/utils/exitConfirm.js`
  - 대기방 방장 자리 칸 `chunkPlayerSlots`(`reserved-host-seat`)·`MatchingPartySlots.jsx`·안내 글 — `frontend/src/domains/game/matching/`, 판 중 설정 탭 `SettingRoomTab.jsx`
  - 모바일: `frontend-mobile/src/domains/game/result/components/actions/ResultActions.jsx`, `result/pages/GameResultPage.jsx`(`CloseTimer`), `matching/components/slots/SlotGrid.jsx`, `ingame/components/sheets/settings/RoomTab.jsx`, `shared/ads/backGate.js`
- 서버 여러 대(방 코드 키 잡아 두기·다른 Node 사람이 옮겨 붙기·비우는 Node의 `NODE_DRAINING`)는 A17 몫 — 이 글엔 안 넣음.

## 결정과 구간 글(06)이 다른 곳 — 결정을 따름

- 판 끝 뒤 방: 06은 방장이 "대기방으로"를 누르면 **새 방**을 만들고 새 코드를 뽑음 → 결정은 판 끝 순간 **같은 코드·같은 설정**으로 서버가 다시 엶 (B-021~055).
- 누가 들어가나: 06은 서버가 끝난 판 사람을 자동으로 끌어다 넣음(파티 방) → 결정은 "대기방으로"를 누른 사람만 (B-056~092). B06-1·Q06-4·B06-4가 같이 풀림.
- 방장: 06은 방장만 방을 만들 수 있고 나머지는 "방장이 새 방을 만드는 중" 기다림 화면(최대 3분, Q06-2) → 결정은 누구든 바로, 원래 방장 자리는 180초 남김 (B-093~128, F-060).
- 설정: 06은 "다음 게임 설정 유지"를 켰을 때만 지난 설정, 아니면 기본값(코드 방이 공개 방으로) → 결정은 늘 지난 설정, 스위치 삭제 (B-021~043, F-058·059, M-007).
- 결과 화면 시간: 06은 제한 없음·판 끝 순간 끊긴 사람만 60초 정리 → 결정 180초 하나의 시계 (B-129~161).
- 결과 화면 "로비로" 확인 글: 06은 "게임에서 나가시겠습니까?" → 결정 "로비로 나가시겠습니까?" (F-042, E-018).

## 개발자용 부록 — 건너뛰어도 됨

- 손잡이: 브 `closeResults`는 "180초가 지났다"는 앞 단계 넘기기용. 180초 규칙 자체를 보는 케이스(H-031~040)는 손잡이를 안 씀.
