# A05a 밤 — 차례·능력·밤 결과 — 시험 케이스 목록

이 글은 밤 차례 순서, 직업마다 고를 수 있는 대상, 같은 직업 2명, 광대에게 찍힌 사람의 능력, 밤 판정과 개인 결과 글, 승패로 이어짐을 겉으로 보이는 결과로 적은 목록임 (목표 백 200 · 화 190 · 모 8 · 브 간단 185 + 어려움 30).

- 맡은 범위: A05를 둘로 나눈 앞쪽. 뒤쪽 A05b(밤 동안 알림 없음·낮 시작 연출·"다 고르면 5초 뒤" 차례 닫기·"밤 종료" 단추)는 안 씀.
- 번호: A05-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-001~499 (A05b는 501~999)
- 종류: 순수 / 흐름 / DB / 화면 상태 / 화면 부품 / 브
- 인원: 판을 차리면 몇 명 판인지 (5~10). "직접" = 방 설정 직접 구성(`roleCompositionMode: 'custom'`), 예 직접{광대1·경비원1} = 광대 1·경비원 1·나머지 시민
- 표 돌리기는 번호 범위 한 줄 + "값" 목록 (값 하나 = 케이스 하나)
- [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀
- 출처 줄임: 결정 = `결정.md`, 고치기 = `고치기_계획.md`, 04 = `04-밤-직업.md`(고치기 전 글 — 결정과 다르면 결정), 화면 문구 = 화면에 적힌 사용자 글
- 사건 이름(지금 코드): 보냄 `submit_night_action`(밤 행동 보내기, 값 `{ gameId, targetId }`, 건너뛰기는 `targetId: null`), 받음 `night_turn_started`(차례 시작, `{ gameId, dayIndex, role, deadline }`) · `night_turn_ended`(차례 끝) · `night_actions_resolved`(판정 끝) · `night_action_result`(개인 결과, 쓴 사람만) · `night_result_applied`(밤 결과, `players`·`victimUuid`·`deathReveals`·`doctorSaved`, 판 끝이면 `winResult`)
- 거절 코드 이름(지금 코드, "어디를 볼지"만): `TARGET_IS_ALLY`·`TARGET_NOT_ALIVE`·`TARGET_NOT_DEAD`·`INVALID_TARGET`·`ACTOR_NOT_ALIVE`·`NOT_ELIGIBLE`·`NOT_YOUR_TURN`·`INVALID_PHASE` (`backend/game-core/phase/night/submit.js`)
- 직업 이름: `JOKER` 광대 · `CITIZEN` 시민 · `DOCTOR` 의사 · `GUARD` 경비원 · `WITCH_HUNTER` 마녀사냥꾼 (화면 이름 `frontend/src/domains/game/ingame/constants/roleReveal/ingameRoleRevealData.js`)
