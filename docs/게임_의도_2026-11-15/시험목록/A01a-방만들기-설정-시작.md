# A01a 방 만들기·설정·시작 조건 — 시험 케이스 목록

이 글은 대기방 중 "방 만들기 → 방 설정 바꾸기 → 시작이 받아들여지는가"까지를 겉으로 보이는 결과로 적은 목록임 (목표 백 200 · 화 230 · 모 6 · 브 간단 140 + 어려움 15 = 591).

- 번호: A01-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리. 이 글은 001~499만 씀(501~999는 A01b 입장·준비·추방·방장·초대).
- 종류: 순수 / 흐름 / DB / Redis / 화면 상태 / 화면 부품 / 브
- 인원: 방·판을 차리면 몇 명인지 줄마다 적음 (판은 5~10명, 4명은 거절 확인만)
- 표 돌리기는 번호 범위 한 줄 + 값 목록 (값 하나 = 케이스 하나)
- 구성 줄임: J 광대 · D 의사 · G 경비원 · W 마녀사냥꾼 · C 시민 (예 `J2D2G2W2` = 광대 2·의사 2·경비원 2·마녀사냥꾼 2)
- [지금 동작] = 출처가 없어 지금 동작을 임시 정답으로 씀 (아래 "결정 대기·출처 없음" 표)
- 범위: 시작은 "받아들여지나(판이 생기나·거절 글)"까지만. 직업 나누기·역할 창·동료 보임은 A02.
