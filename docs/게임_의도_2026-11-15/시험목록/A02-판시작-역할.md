# A02 판 시작·역할 — 시험 케이스 목록

이 글은 판 시작(역할 구성·나누기·시작 알림)과 역할 확인 10초, 같은 직업끼리 보임을 겉으로 보이는 결과로 적은 목록임 (목표 백 280 · 화 200 · 모 8 · 브 간단 180 + 어려움 20 = 688).

- 번호: A02-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
- 종류: 순수 / 흐름 / DB / 화면 상태 / 화면 부품 / 브
