# A06 판 중 채팅·이모티콘 — 시험 케이스 목록

이 글은 판 안 채팅(낮·재판·밤 같은 직업·죽은 사람끼리)과 이모티콘, 신고 때 남는 채팅 증거를 겉으로 보이는 결과로 적은 목록임 (목표 백 100 · 화 200 · 모 10 · 브 간단 160 + 어려움 20 = 490).

- 번호: A06-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
- 종류: 순수 / 흐름 / DB / 화면 상태 / 화면 부품 / 브
- 인원: 판을 차리면 몇 명 판인지 (5~10). "직접 구성" = 방 설정에서 직업 수를 정함(예 의사 2명), 안 적으면 자동 구성(6명부터 의사·8명부터 경비원·10명부터 마녀사냥꾼)
- 표 돌리기는 번호 범위 한 줄 + "값"에 값 목록 (값 하나 = 케이스 하나)
- [단위 2] = `고치기_계획.md` 단위 2 "시험 단계가 꼭 넣을 케이스", [지금 동작] = 출처가 없어 지금 동작을 임시 정답으로 씀
- @realtime = 진짜 시간으로 기다림(0.5초·1초 간격, 3초 말풍선), @hard = 브라우저 사람 여럿, @safari = 사파리에서도 돎
- `expectReadable` = 보임을 진짜로 봄(화면 안·안 가려짐·글자 대비 4.5 이상, `시험_계획.md` 3-6)
