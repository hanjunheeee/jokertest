# A09 끊김·나가기·탈주 — 시험 케이스 목록

이 글은 판 도중 끊김(60초 기다림)·스스로 나가기·탈주 기록과 탈주 대기·죽은 사람 풀기·대기방 끊김(15초)에서 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 340 · 화 260 · 모 12 · 브 간단 120 + 어려움 60, 합 792).

- 번호: A09-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리. 백은 순수 001~060 · 흐름 101~331 · DB 401~449, 화는 상태 001~183 · 부품 201~277.
- 종류: 순수 / 흐름 / 요청 / DB / 화면 상태 / 화면 부품 / 브
- 인원: 판을 차리면 "(N명 판)"으로 줄마다 적음. 대기방은 "(N명 방)". 백 판 도우미·브 `table.setup` 모두 5명 이상.
- 표 돌리기는 번호 범위 한 줄 + "값" 목록 (값 하나 = 케이스 하나)
- [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀, [결정 대기] = 정해지기 전엔 시험 코드 안 씀
- 받은 버그 표(시험_계획 2-6)엔 A09 몫이 없음. 대신 구간 글 07의 버그 B07-1(죽고 끊긴 사람이 대상에 "산 사람"으로 들어감)을 [B07-1]로 표시함.
- 사건(event, 서버와 화면이 주고받는 알림) 이름·칸 이름은 지금 코드(커밋 `648f52fb`)에서 찾음. 기대값은 아래 출처에서만 가져옴.
- 시간: 백은 가짜 시계(시험이 돌리는 시계)로 59·60·61초를 봄. 브는 3-5 표대로 60초를 손잡이 `/e2e/games/:gameId/expire-graces`(끊김 60초 바로 끝내기)로 넘기는 케이스와 진짜로 기다리는 `@realtime` 케이스를 나눔(끊김을 진짜 시간으로 기다리는 케이스 = 간단 6 + 어려움 19 = 25개, 계획 3-5의 20개보다 조금 많음).
- 브 "보임"은 `expectReadable`(보임·화면 안·안 가려짐·글자 대비 4.5 이상 확인 도우미, 시험_계획 3-6)로 봄. 확인 창(`window.confirm`)·알림 창(`window.alert`)은 브라우저 창이라 글만 봄(대비는 못 봄).
- 코드에서 찾은 이름 (정답 아님, 찾기용)
  - 끊김 기다림: `DISCONNECT_GRACE_MS = 60000`(`backend/socket/gameSession/core/constants.js`), `beginDisconnectGrace`·`cancelDisconnectGrace`·`expireDisconnectGrace`(`connection/grace.js`), 탈락 이유 `DISCONNECT_GRACE_EXPIRED`, 나가기 이유 `PLAYER_LEFT`, 죽은 이유 `DISCONNECT`(`game-core/departure/eliminate.js`)
  - 판 사건: `leave_game_session`(판 나가기), `get_session_snapshot`(내 판 상태 묻기), `session_player_connection_changed`(누가 끊김·돌아옴, `{ gameId, uuid, isConnected }`), `player_eliminated`(탈락), `session_participation_changed`(참여 바뀜·방장), `session_self_progress`(내 제출 상태), `tribunal_vote_resolved`(재판 결과·취소)
  - 스냅샷 거절 코드: `FORFEITED_FROM_SESSION` + 글 "연결이 끊겨 이 게임에서 제외되었습니다. 다시 참여할 수 없습니다.", `SESSION_NOT_FOUND`, `NOT_A_PARTICIPANT`, `SESSION_ROUTING_PENDING`
  - 탈주: 표 `game_desertions`(칸 `user_id`·`game_id`·`reason`·`deserted_at`·`blocked_until`, 유일 목차 `game_desertions_user_game_unique`), 이유 `LEFT_ALIVE`(산 채로 나감)·`DISCONNECT_TIMEOUT`(60초 못 돌아옴), 서비스 `recordDesertion`·`getDesertionBlock`·`loadActiveDesertions`·`desertionWaitMessage`·`cooldownMsFor`·`computeBlock`·`kstDayStart`·`formatWait`(`backend/services/game/desertion.js`), 시험 손잡이 `__setRepositoryForTests`·`__resetForTests`
  - 입장 거절: 코드 `DESERTION_COOLDOWN` + `message`("탈주로 ○분 ○초 뒤에 참여할 수 있습니다.") + `retryAfterMs`(남은 ms) + `blockedUntil`(ISO 시각). 길: `create_room`(답 callback(답 받는 함수)), `join_room_by_code`·`join_public_room`·`join_matchmaking`(`room_join_failed` 알림), `accept_game_invite`(답 callback)
  - 대기방: `ROOM_RECONNECT_GRACE_MS = 15000`, `get_current_room`, `leave_room`, `player_left_room`, `host_changed`
  - 다른 기기: `force_disconnect` 이유 `REPLACED_BY_OTHER_LOGIN`·`REPLACED_BY_SAME_SESSION`
  - 화면: 확인 창 글 `EXIT_CONFIRM_MESSAGES`(ALIVE·DEAD·PLAIN·RESULT)·`selectExitConfirmMessage`·`selectExitStatusNotice`·`createExitConfirmController`·`isPopNavigationBlocked`(`frontend/src/domains/game/ingame/utils/exitConfirm.js`), 대상 목록 `isSessionPlayerAlive`·`buildDayVoteTargets`·`buildNightActionTargets`(`utils/actionTargets.js`), 카드 상태 `mergeSourcePlayerWithPreview`, 판 없음 판정 `isSessionGoneResponse`(`utils/sessionEnd.js`), 빠진 까닭 글 `hooks/snapshotSync/request.js`, 사망·나가기 안내 창 `components/deadChoice/InGameDeadParticipantChoice.jsx`(모바일 `overlays/DeadChoiceOverlay.jsx`·`hooks/overlays/useDeadChoice.js`), 모바일 채팅 알림 `utils/talk/playerNotices.js`
  - 관리자: `GET /admin-api/members/:uuid` 칸 `desertions[]`(`id`·`gameId`·`reason`·`desertedAt`·`blockedUntil`·`active`, 최근 50줄), 화면 `MemberDetailPage.jsx` "탈주 기록"
