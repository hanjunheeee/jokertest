# A18 설정·배포·광고 — 시험 케이스 목록

이 글은 운영 규칙(어디서나 5~10명)·서버 켜기 검사·점검·서버 끄기·확인 스크립트·부하·배포 스크립트·모바일 광고에서 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 100 · 화 40 · 모 14 · 브 간단 20 + 어려움 10, 합 184).

- 번호: A18-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
  - 백: 순수 001~056 · 흐름 101~123 · 스크립트·프로세스 201~222 · DB 301~312
  - 화: 상태 001~030 · 부품 201~210
- 종류: 순수 / 흐름 / 요청 / 프로세스(서버·스크립트를 따로 띄워 종료 코드·출력 봄) / DB / 화면 상태 / 화면 부품 / 브
- 인원: 판·대기방을 차리면 "(N명 판)"·"(N명 방)"으로 적음. 백 판 도우미·브 `table.setup` 모두 5명 이상 (4명은 거절을 보는 줄만)
- 표 돌리기는 번호 범위 한 줄 + "값" 목록 (값 하나 = 케이스 하나)
- [단위 18] = `고치기_계획.md` 단위 18 "꼭 넣을 케이스", [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀, [결정 대기] = 정해지기 전엔 시험 코드 안 씀
- 받은 버그 9개(시험_계획 2-6)는 A18에 걸린 것 없음
- 환경값(서버 설정 값)은 **이름만** 적음. 값은 시험 안에서 만든 가짜 값(예 무작위 48자)만 씀, `.env`·`.env.*` 파일은 안 읽음
- 서버·스크립트를 따로 띄우는 시험(종류 "프로세스")은 작업 폴더를 빈 임시 폴더로 둠 — `backend/index.js`가 맨 앞에서 `dotenv`(작업 폴더의 `.env` 읽기)를 불러서, 저장소 폴더에서 띄우면 개발자 `.env` 값이 섞임
- 출력·보고서에 비밀 값이 안 남는지도 봄: 거부 글에 값 이름만 있고 넣은 값 글자는 없음
- 브 `@serial` = 서버 전체에 걸려 한 번에 하나만 돎(점검), `@shutdown` = 시험 서버를 끄고 다시 켬(serial 프로젝트), `@realtime` = 손잡이 없이 진짜 시간 기다림
- 브 "보임"은 `expectReadable`(보임·화면 안·안 가려짐·글자 대비 4.5 이상 확인 도우미, `e2e/helpers/visible.js`)로 봄
- 코드에서 찾은 이름 (정답 아님, 찾기용)
  - 인원 규칙 `getMinPlayers`·`getRequiredPlayers`·`getSupportedRoomSizes`(`backend/socket/matchmaking/core/config.js`), `getMinSupportedPlayers`·`getMinRoomCapacity`(`backend/game-core/setup/constants.js`), 판 입력 검사 `validateSessionInput`(`game-core/setup/input.js`), 정원 검사 `isAllowedMaxPlayers`(`backend/validations/room/create.js`), 시작 거절 코드 `MIN_PLAYERS_NOT_MET`
  - 환경 판정 `isProduction`·`isUnknownNodeEnv`(`backend/config/nodeEnv.js`), 필수 값 `findMissingEnv`·`findWeakSecrets`·`isStartupFatal`(`config/requiredEnv.js`), 시험 손잡이 `isE2eHooksEnabled`·`assertNoE2eInProduction`·`getMailTestOutboxDir`·`getOAuthTestBaseUrl`(`config/e2eHooks.js`), 연결 풀 경고 `describePoolWarning`(`config/cluster.js`)
  - 표 준비 `ensureSchemaReady`·`summarize`(`backend/db/schemaReadiness.js`), 시작 실패 줄 `[STARTUP] 실패 — <까닭>`, 성공 줄 `[STARTUP] 성공`
  - 켤 때 읽기: 점검 `reloadMaintenance`, 금지어 `reloadBannedWords`, 탈주 막힘 `loadActiveDesertions`, 판 설정 값 `reloadGameSettings` (`backend/index.js` 시작 줄)
  - 점검: 거절 `rejectDuringMaintenance`(`socket/matchmaking/join/maintenanceGate.js`) 답 `{ ok:false, code:'MAINTENANCE', message, endsAt }`, 시계 `createMaintenanceClock`(`services/ops/maintenanceClock.js`), 안내 사건 `maintenance_notice`(`services/ops/maintenanceNotice.js`), 판 끝 `game_ended` reason `MAINTENANCE`, 방 닫힘 `room_deleted` code `MAINTENANCE`
  - 서버 끄기 `createShutdown`(`backend/utils/processLifecycle.js`), 사건 `server_shutdown` 값 `{ code:'SERVER_SHUTDOWN', message }`, `/health`의 `draining`(새 손님 안 받기 표시)
  - 시험 손잡이 경로 `createE2eRouter`(`backend/routes/e2e.routes.js`, `/e2e/...`)
  - 스크립트: `tools/시험도구/ensure-tests.js`, 부하 `parseArgs`(`backend/scripts/loadtest/run.js`)·`checkTargetAllowed`·`assertLocalDatabase`(`loadtest/target.js`), 씨앗 `backend/scripts/seed-dev-testers.js`·`seed-test-currency-products.js`, 배포 `resolveNodeCount`·`planNodes`·`renderComposeNodes`(`deploy/scripts/gen-nodes.js`), `drain_node`·`rolling`(`deploy/ci/scripts/deploy/nodes.sh`, 시험용 가짜 `backend/tests/deploy/fixtures/fakeCompose.sh`)
  - 화면 점검: `useMaintenanceStore`(`frontend/src/domains/maintenance/store/maintenanceStore.js`), 글 `stageOf`·`formatRemaining`·`formatClock`·`describeWinReason`(`utils/maintenanceText.js`), `bigNoticeCopy`·`bandCopy`(`utils/noticeCopy.js`), 띠 `[data-maintenance-band]`, 큰 안내 `role="alertdialog"`
  - 모바일 광고: `readAdConfig`·`slotMode`(`frontend-mobile/src/shared/ads/adConfig.js`), `shouldShowBanner`(`bannerRoutes.js`), `pickGameKey`·`shouldOpenInterstitial`·`secondsLeft`(`interstitialRule.js`), 기억 `mmc.ads.seenGames`(`seenGames.js`), 창 `InterstitialAd.jsx`(`[data-interstitial-ad]`), 뒤로 가기 문지기 `setBackGate`(`backGate.js`)
