# A04 재판 — 시험 케이스 목록

이 글은 재판 영역에서 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 220 · 화 180 · 모 12 · 브 간단 180 + 어려움 40, 합 632).

- 번호: A04-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리. 백은 순수 001~080 · 흐름 101~230 · DB 301~310, 화는 상태 001~110 · 부품 201~270.
- 종류: 순수 / 흐름 / 요청 / DB / Redis / 화면 상태 / 화면 부품 / 브
- 인원: 판을 차리면 몇 명 판인지 (5~10)를 줄마다 괄호로 적음. 순수 판정 표는 "투표할 사람 n명"(= 피고 포함 n+1명 판).
- 표 돌리기는 번호 범위 한 줄 + "값" 칸에 값 목록 (값 하나 = 케이스 하나)
- [버그 8] = 받은 버그 다시 생기는지 잡는 케이스, [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀, [결정 대기] = 정해지기 전엔 시험 코드 안 씀
- 사건(event, 서버와 화면이 주고받는 알림) 이름·칸 이름은 지금 코드(커밋 `10fd1a52`)에서 찾음. 기대값은 아래 출처에서만 가져옴.
- 브 "보임"은 `expectReadable`(보임·화면 안·안 가려짐·글자 대비 4.5 이상 확인 도우미, 시험_계획 3-6, 도우미 담당이 만듦)로 봄.
- 브 줄에 "PC n명 / 모바일 n명"이 같이 있으면 모바일 값은 같은 이름의 `e2e/tests/mobile/` 파일로 감.
- 브 `@realtime` 표시 = 손잡이(`/e2e` 시간 건너뛰기) 안 쓰고 진짜 시간으로 기다림. 재판 시간 규칙을 보는 판은 재판 15초로 둠(시험_계획 3-5).
