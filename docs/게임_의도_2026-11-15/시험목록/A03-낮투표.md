# A03 낮 토론·투표 — 시험 케이스 목록

이 글은 낮 토론·투표 영역(다 내면 5초 뒤 판정, 기권이 많으면 재판 없음)에서 시험할 것을 겉으로 보이는 결과로 적은 목록임 (목표 백 300 · 화 240 · 모 12 · 브 간단 280 + 어려움 40 = 872).

- 번호: A03-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
- 종류: 순수 / 흐름 / DB / 화면 상태 / 화면 부품 / 브
- 인원: 판을 차리면 몇 명 판인지 (5~10)
- 표 돌리기는 번호 범위 한 줄 + "값" 목록 (값 하나 = 케이스 하나, 범위 길이 = 값 수)
- [버그 9] = 받은 버그 9 "기권이 다수인데 한 명이 투표하면 피고인으로" 다시 생기는지 잡는 케이스, [지금 동작] = 출처 없어 지금 동작을 임시 정답으로 씀
- 브 표시: `@game`(판 씀, 전부) · `@realtime`(진짜 시간 기다림, 손잡이 `advance` 안 씀) · `@hard`(H 전부) · `@safari`(사파리에서도) — `@smoke`는 시험 코드 쪽이 파일마다 하나 고름

### 시험이 볼 곳 (코드에서 찾은 이름 — 정답 아님)

- 서버→화면 사건: `day_phase_changed`(낮 안 단계 바뀜), `phase_settle_started`(마감 당김, `{ gameId, phase: 'DAY', dayIndex, role: null, deadline }`), `day_vote_resolved`(결과: `outcome`·`tribunalTargetUuid`·`publicVoteCount`(산 사람 수)·`publicAbstainCount`(기권 수)·재판이면 `tribunalDeadline`), `session_self_progress`(내 진행 수), `day_chat_message_received`
- 화면→서버 사건: `ready_for_day_vote`(투표하자), `cast_day_vote`(`targetId: null` = 기권), `submit_game_chat_message`, `get_session_snapshot`. 지운 사건 `resolve_day_vote`
- 결과 값 `outcome`: `TRIBUNAL`(재판) · `TIE`(동점, 밤) · `ABSTAIN_MAJORITY`(기권이 최다 득표 이상, 밤) · `ABSTAINED`(전원 기권, 밤)
- 거절 코드(낮 표): `SELF_TARGET_NOT_ALLOWED` · `TARGET_NOT_ALIVE` · `INVALID_TARGET` · `ACTOR_NOT_ALIVE` · `INVALID_PHASE` · `INVALID_DAY_PHASE` · `DAY_VOTE_ALREADY_RESOLVED` · `INVALID_GAME_ID` · `VOTE_PERSIST_FAILED`
- 서버 파일: 표 세기 `backend/game-core/phase/day/ballots.js`(`tallyDayVoteOutcome`), 표 받기 `game-core/phase/day/vote.js`, 준비 `game-core/phase/day/ready.js`, 5초 `backend/socket/gameSession/phase/settle.js`(`SETTLE_DELAY_MS`, 시험은 run에 `settleDelayMs`)·`phase/day.js`(`settleDayVoteIfComplete`), 나감 반영 `socket/gameSession/departure/apply.js`, 스냅샷 `game-core/snapshot/session.js`·`progress.js`(`self.hasSubmittedDayVote`·`dayVoteTargetUuid`), DB 표 `vote_participations`(마이그레이션 0008)
- 화면 파일: 결과 검사 `frontend/src/domains/game/ingame/utils/dayVoteResolve.js`, 마감 당김 `utils/selectInGameTimebarStatusMessage.js`(`applyPhaseSettleStarted`, 글 "[5초 뒤 마감]"), 현황 창 `components/vote/InGameVoteStatusContent.jsx`, 행동 줄 `components/timebar/InGamePhaseActionRow.jsx`, 기권 단추 `components/actions/InGameCornerActionPanel.jsx`, 제출 `hooks/useInGameDayVoteSubmit.js`·`utils/voteSubmitPatch.js`, 모바일 `frontend-mobile/src/domains/game/ingame/components/actions/VoteStatusContent.jsx`·`components/timebar/Timebar.jsx`·`hooks/actions/buildRowActions.js`·`hooks/timebar/useTimebar.js`
- 표 세기 값 표기: "X 3·Y 1·기권 3" = X가 3표, Y가 1표, 기권 3 (안 낸 표는 마감 때 기권). X는 자기를 못 찍으니 X 표는 다른 사람·기권 쪽에 셈
