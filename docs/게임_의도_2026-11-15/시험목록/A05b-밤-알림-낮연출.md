# A05b 밤 알림·낮 시작 연출·5초 차례 — 시험 케이스 목록

이 글은 밤에 누구에게 무엇이 가나(안 가나), 낮이 될 때 모두가 보는 암살 영상·"의사가 살렸다" 글, 직업이 다 고르면 5초 뒤 차례가 닫히는 규칙을 겉으로 보이는 결과로 적은 목록임 (목표 백 200 · 화 190 · 모 8 · 브 간단 185 + 어려움 30).

- A05를 둘로 나눈 뒤쪽. 앞쪽 A05a(차례·능력·밤 결과 풀기)는 번호 001~499, 이 글은 **501~999**.
- 번호: A05-B(백)·F(화)·M(모)·E(브 간단)·H(브 어려움)-세 자리
- 종류: 순수 / 흐름 / 화면 상태 / 화면 부품 / 브 / 브 @hard
- 인원: 판을 차리면 몇 명 판인지 (5~10), "무엇" 칸 끝 괄호에 적음
- 표 돌리기는 번호 범위 한 줄 + 값 목록 (값 하나 = 케이스 하나)
- [버그 5] = 받은 버그 5번(암살 영상이 광대와 당한 사람에게만) 다시 생기는지 잡는 케이스, [임시 n] = `결정.md` "반장이 임시로 정한 것" n번, [지금 동작] = 출처가 없어 지금 동작을 임시 정답으로 씀
- 브 `@realtime` = 5초를 손잡이(`/e2e` 시험 길)로 건너뛰지 않고 진짜로 기다림, 허용 폭 ±1.5초 (`시험_계획.md` 3-5)
- "보임" = `expectReadable`(글이 화면 안·안 가려짐·글자와 바탕 대비 4.5 이상, `시험_계획.md` 3-6)

## 코드에서 찾은 이름 (어디를 볼지만, 정답 아님)

- 서버→화면 사건: `night_turn_started`·`night_turn_ended`(차례 시작·끝), `phase_settle_started`(마감 당김(5초) 알림, 값 `{ gameId, phase, dayIndex, role, deadline }`), `night_actions_resolved` → `night_action_result`(쓴 사람 개인 결과) → `night_result_applied`(밤 결과 공개 값, `victimUuid`·`deathReveals[{victimUuid, source}]`·`doctorSaved`)
- 없어진 사건: `night_action_success`, `night_presentation_wait`(서버→화면), `acknowledge_night_action_success`, `resolve_night`(화면→서버)
- 없어진 스냅샷 칸: `nightSuccessRecovery`, `presentationWaiting` (커밋 453d9599에서 지움)
- 서버 파일: `backend/socket/gameSession/phase/settle.js`(5초, `SETTLE_DELAY_MS`), `phase/night/turn.js`, `phase/night/finalize.js`, `backend/game-core/phase/night/prepare.js`·`payloads.js`
- 화면 표시: `[data-ingame-dawn-report="KILLED|SAVED"]`(글 창), `[data-ingame-night-success-kill]`(암살 영상), `[data-ingame-dawn-report-message]`(영상 위 글), `[data-ingame-phase-settle]`(시간 바 5초 표시, 글 "[5초 뒤 마감]")
