# 회원 기능 (2026-11-09, 개발자용)

## 약관·동의
- 표: `terms_versions`(종류 TERMS·PRIVACY, 버전, 제목, 본문·주소, 시행일, 필수 여부, 만든 관리자), `user_terms_agreements`(uuid, 약관 버전 id, 동의 시각, IP 없음) — 마이그레이션 `0026-add-terms-agreements`
- 자리용 문서 2개(버전 `0.1-placeholder`)만 넣음. 실제 문구는 관리자 서버가 **새 버전 줄을 넣는 방식**으로 채움 (옛 줄 고치지 말 것, 동의 기록이 버전 id를 가리킴)
- 지금 버전 = 종류마다 시행일 지난 것 중 가장 늦은 것(같으면 id 큰 것). 시행일을 미래로 넣으면 그날부터 재동의 뜸
- 가입(이메일·소셜) 본문에 `agreedTermsVersionIds: [id]`, `ageConfirmed: true` 필수
  - 서버 검사: 14세 확인 체크 → 생일로 만 14세 미만 거절(한국 날짜) → 지금 필수 약관 전부 → 동의 기록(가입 트랜잭션 안)
  - 코드: `AGE_CONFIRM_REQUIRED`·`AGE_UNDER_14`·`TERMS_AGREEMENT_REQUIRED` (모두 400)
- API: `GET /auth/terms`(로그인 전), `GET /user/me/terms` → `{ pending, reconsentRequired }`, `POST /user/me/terms/agree { agreedTermsVersionIds }`(옛 버전이면 409 `TERMS_VERSION_OUTDATED`)
- 화면: 가입 칸에 전체 동의·약관별 동의+보기(전체 보기 창)·만 14세 줄, 로그인 뒤 재동의 창(동의 전엔 안 닫힘, 서버가 API를 막지는 않음)

## 회원 탈퇴
- `POST /user/me/withdraw { password }` (소셜 전용 계정은 `{ confirmEmail }` = 계정 이메일 그대로)
- 진행 중인 판이면 409 `WITHDRAW_IN_GAME`, 비번 5번 틀리면 15분 429 `WITHDRAW_LOCKED`
- 한 트랜잭션: 세션 전부 끊기·소셜 연결·친구·신청·즐겨찾기·차단 지움·대기 초대 취소·접속 줄·재설정 토큰·인증 줄 지움·전적 이름 `탈퇴한 사용자` → 계정 `status=WITHDRAWN`, 이메일 `withdrawn-<uuid>@withdrawn.invalid`, 닉네임 `탈퇴<uuid32자>`, 생일·전화·사진 비움, `deleted_at` 채움
- 지갑·장부·동의 기록은 uuid로 남음(재화는 사라짐 안내). 같은 이메일·닉네임으로 다시 가입 가능
- 끝나면 그 사람 소켓에 `force_disconnect { code: ACCOUNT_WITHDRAWN }`
- 화면: 계정 관리(비밀번호 바꾸는 창) 비밀번호 칸 아래, 되돌릴 수 없다는 확인 창 → 로그인 화면으로

## 이메일 바꾸기
- `POST /user/me/email/code { newEmail, currentPassword? }` → 새 주소로 번호(가입 인증 표, 목적 `EMAIL_CHANGE`, 번호 해시에 요청한 uuid를 섞음)
- `POST /user/me/email/verify { newEmail, code }` → 바꿈 + 옛 주소로 "바뀌었음" 메일(새 주소는 가림)
- 비번 있는 계정은 현재 비번 필요, **소셜 전용 계정은 비번 없이 번호만**(결정). 남이 쓰는 주소 409 `EMAIL_IN_USE`
- 제한: 다시 보내기 1분(설정 `SIGNUP_EMAIL_RESEND_COOLDOWN_MS`), 번호 틀리기 5번, 한 사람 번호 요청 1시간 5번·확인 15분 20번
- 메일 실패는 503 `MAIL_SEND_FAILED`로 알림(로그인한 본인이라 숨길 것 없음)
- `GET /user/me/account` → `{ email, hasLocalPassword }` (두 칸이 본인 확인 칸을 고름)

## 그 밖
- 구글·디스코드 로그인·소셜 가입 마무리도 `users.last_login_at`
- 비번 변경 응답 `reloginRequired: true`면 안내 1.5초 뒤 로그인 화면
- 쿠폰: `POST /economy/coupons/redeem`(운영 받침 몫) 화면 — 데스크톱 상점 재화 아래 "쿠폰 입력", 모바일 상점 위 줄 "쿠폰", 성공하면 지갑 다시 받기
- 화면 버전: 빌드 때 `frontend/scripts/appVersionPlugin.mjs`가 `git해시-빌드시각`을 넣고 `version.json` 내보냄. 5분마다·탭 돌아올 때 비교, 다르면 아래 안내 띠(`/ingame`에선 안 띄우고 판 끝나면). 개발 서버는 확인 안 함
- 칭호·평판 삭제(0027), 프로필 판 수까지 `user_stats` 기준(사용자 결정)
