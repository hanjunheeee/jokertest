# 직접 플레이 체크리스트 (2026-11-18)

맥북 PC 화면에서 가입부터 판 끝·나가기까지 손으로 한 바퀴 돌며 "기능이 되는지"를 줄마다 표시하는 목록임 (103줄).

- 통과 기준은 `docs/게임_의도_2026-11-15/`의 의도 글·`결정.md`·시험 목록, `docs/맥북_이어받기_2026-11-17/눈으로_확인할_것.md`, `docs/이메일_토스_설정.md`에서 뽑음
- 근거를 못 찾은 줄은 통과 칸 끝에 "(확인 필요)"
- "(11-18 바뀜)" = 2026-11-18 사용자 결정으로 고친 다섯 가지(고치기 끝남, 단위 시험 통과 — 화면에서는 이 목록으로 처음 확인함), 바뀐 뒤 모습이 통과 기준
- 이 글은 기능만 봄 — 색·겹침·글자 잘림은 안 봄

## 돌리는 법

- 개발 서버: 저장소 맨 위에서 `npm run dev` → 화면 http://localhost:5173 · 백엔드 4000 · 개발 DB(데이터 저장소) `joker_dev`
- 시험 계정: tester1~tester10 (`tester1@example.test` 꼴, 이메일 인증 끝남). 비밀번호는 `backend/.env`의 `DEV_TESTER_PASSWORD` 값 (이 글엔 안 적음)
- 여러 사람 창: `bash tools/시험도구/여러창/open.sh room 1 2 3 4 5` → tester1이 방을 만들고 나머지가 들어온 대기방까지 감. 번호를 늘리면 6~10명
- `room` 없이 번호만 주면(`open.sh 1 2`) 로비까지만 감. 창 아래 단추 줄로 창을 바꿈, Ctrl+C로 다 닫음
- 내 진짜 계정(소셜 로그인·메일·결제)은 평소 크롬에서 http://localhost:5173
- 개발 서버엔 봇 없음(자리마다 진짜 계정), 자동 매칭 꺼짐 → 방 코드로 모임, 판은 5명부터
- 메일·토스·소셜 줄은 맨 끝 "바깥에서 준비돼야 하는 것"이 먼저 끝나 있어야 함

## 권하는 순서

1. **혼자, 크롬 내 계정**: 가입·로그인(로그-01~09) → 이메일·비밀번호(비번) → 소셜(소셜) → 결제·상점(상점-01~09)
2. **둘이서, `open.sh 1 2`**: 친구-01~04, 로그-10 (크롬에서 tester1로 로그인)
3. **방, `open.sh 1 2 3 4 5 6`(로비까지)**: 방-01~11, 친구-05·06
4. **5명 판 4번, `open.sh room 1 2 3 4 5`** — 판마다 판-04(첫 자리 직업 적기)를 같이 함
   - 판 A (기본 흐름 → 시민 승): 판-01~16 → 둘째 날 판-22 → 판-23(크롬 내 계정으로 코드 입장) → 광대를 처형해 판-24 → 끝-01~08 (끝-08로 판 B 시작)
   - 판 B (재판 없는 날들): 판-17~21, 나감-05·08 → 끝까지 아무렇게나 마침
   - 판 C (방 설정 광대 2명): 판-25(빨리 광대 승), 나감-01·02
   - 판 D (맨 마지막, 탈주한 tester는 5분 막힘): 나감-03·04·06·07
5. **6~10명 판 4번** (판 D보다 먼저 해도 됨): 6명 자동(큰판-01·02) → 6명 직접 지정(큰판-06) → 8명 광대 2(큰판-03·05) → 10명(큰판-04)
6. 상점-10(스킨 끼기)은 판 A 전에 끼워 두고 판 A 역할 확인 창에서 봄
