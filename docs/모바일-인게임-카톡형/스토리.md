# 모바일 인게임 카톡형 스토리

주인공: 폰을 세로로 들고 게임하는 사람.

### 1. 판 들어오기 [첫 버전]
- 사용자: 대기방에서 게임이 시작되면 그대로 기다림
- 프로그램: 역할 공개 연출을 지금처럼 화면 전체로 보여 준 뒤 카톡형 화면으로 넘어감
- 확인 기준: 연출이 끝나면 위 단계 줄 + 초상 띠 + 채팅방 + 입력칸이 한 화면에 다 보임
- 잘못되면: 연출 중 연결이 끊기면 지금처럼 다시 붙어 이어서 보여 줌
- 근거: 연출은 그대로 두기로 함

### 2. 지금 상황 보기 (위 단계 줄) [첫 버전]
- 사용자: 맨 위 줄을 봄, 궁금하면 누름
- 프로그램: "제 2일 · 낮 토론 · 0:45"를 늘 보여 줌, 누르면 진행 바가 펼쳐짐
- 확인 기준: 남은 시간이 초마다 줄고, 단계가 바뀌면 글도 바뀜
- 잘못되면: 서버에서 마감 시각이 안 오면 시간 자리는 비우고 단계 이름만 보임
- 근거: 맨 위 얇은 한 줄로 하기로 함

### 3. 사람들 보기 (초상 띠) [첫 버전]
- 사용자: 초상 띠를 옆으로 넘겨 보거나, 띠를 펼쳐 카드 판을 크게 봄
- 프로그램: 참가자 초상을 한 줄로 보여 줌, 펼치면 지금 카드 판처럼 크게 보여 줌
- 확인 기준: 10명 판에서도 띠가 한 줄로 넘어가고, 펼치고 접기가 됨
- 잘못되면: 사람이 나가면 띠에서 바로 빠지거나 표시가 바뀜
- 근거: 카드 판은 위 띠로 줄이고 누르면 펼치기로 함

### 4. 낮 토론 채팅 [첫 버전]
- 사용자: 말을 쓰고 보냄, 남의 말을 위아래로 넘겨 읽음
- 프로그램: 남의 말은 왼쪽(초상 + 닉네임 + 말풍선), 내 말은 오른쪽, 새 말이 오면 아래로 쌓임
- 확인 기준: 말이 많이 오가도 읽기 편하고, 키보드가 올라와도 입력칸과 마지막 말이 보임
- 잘못되면: 보내기 실패면 지금처럼 입력칸 위 한 줄로 안내함(서버가 받아야 목록에 들어가서 말풍선별 표시는 없음), 위로 올려 읽는 중엔 새 말이 와도 화면이 안 끌려 내려감
- 근거: 지금 채팅 칸이 좁아 낮 토론 때 읽기 힘들다는 불편

### 5. 이모티콘 [첫 버전]
- 사용자: 초상 띠에서 내 초상을 길게 눌러 이모티콘을 고름 (지금 내 카드 길게 누르기와 같음)
- 프로그램: 채팅방에 큰 이모티콘 메시지로 남기고, 초상 띠의 내 초상에도 잠깐 띄움
- 확인 기준: 남이 보낸 이모티콘도 채팅방과 띠 둘 다에 보임
- 잘못되면: 보내기 실패면 지금처럼 안내
- 근거: 이모티콘 위치 정한 것

### 6. 투표·재판 [첫 버전]
- 사용자: 초상을 눌러 카드 메뉴에서 투표하거나, 아래 버튼으로 투표 현황을 봄
- 프로그램: 카드 메뉴·투표 현황 창은 지금 것을 그대로 씀, 재판 연출과 재판 채팅도 지금처럼 화면 위에 뜸
- 확인 기준: 투표가 서버에 들어가고, 재판 연출이 끝나면 카톡형 화면으로 돌아옴
- 잘못되면: 투표 실패면 지금처럼 안내
- 근거: 초상 누르면 카드 메뉴, 연출은 그대로

### 7. 밤 행동·조커 채팅 [첫 버전]
- 사용자: 밤에 초상을 눌러 대상을 고름, 조커면 조커끼리 채팅함
- 프로그램: 밤엔 채팅 목록이 통째로 조커 채팅으로 바뀜(지금 동작). 밤 동안 채팅방 맨 위에 "조커 채팅" 표시를 띄우고 말풍선 색을 바꿈
- 확인 기준: 밤 채팅이 낮 채팅과 한눈에 구분됨, 누가 볼 수 있는지는 지금 동작 그대로
- 잘못되면: 대상 고르기 실패면 지금처럼 안내
- 근거: 채널은 방 하나에 표시로 구분하기로 함

### 8. 죽음·알림, 게임 끝 [첫 버전]
- 사용자: 처형·사망 소식을 채팅방에서 봄
- 프로그램: "○○님이 처형됐습니다" 같은 알림을 가운데 회색 줄로 넣고, 죽은 사람 초상은 띠에서 흐리게, 게임이 끝나면 지금처럼 결과 화면으로 감
- 확인 기준: 알림이 말풍선과 섞이지 않고 구분됨, 결과 화면까지 끝까지 감
- 잘못되면: 결과를 못 받으면 지금 결과 화면 흐름 그대로
- 근거: 시스템 알림은 회색 줄로 하기로 함

### 9. 폰 가로 [나중에]
- 회의 뒤에 정함. 그때까지 지금 가로 배치 그대로.

### 10. 태블릿·데스크톱·서버 바꾸기 [안 함]
- 태블릿은 데스크톱처럼 둠. 이번 범위는 폰 세로만.
