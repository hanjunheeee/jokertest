## 확인 방법
- 자동: `cd frontend-mobile && npm test` (10개 통과), 인게임 폴더 코드 검사 0, 빌드 성공.
- 직접: 로컬 서버 + 시험 계정 4명(봇 3)으로 판 3번. 스크린샷은 `스크린샷/`.
- 알림 줄은 실제 이탈 사망 1건(tester4)으로 확인, 처형 알림은 브라우저 안에서 명단을 바꿔 확인(서버 처형으로는 판이 빨리 끝나 못 봄).
