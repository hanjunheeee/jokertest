## 약속
### 채팅방 데이터 → 채팅방
- 내주는 것: `useTalkFeed()` → 채팅방 한 줄 목록(설계.md 데이터 모양), 시각 순.
- 기대는 것: 채팅 세션·참가자 컨텍스트 안에서 불림.
- 실패하면: 빈 목록. 오류를 던지지 않음.

### 섞기 함수
- `buildTalkFeed({ messages, notices, emojis, localPlayerId, joker })` → 줄 목록.
- 같은 시각이면 들어온 순서 유지. 명단에 없는 보낸 사람은 이미 세션이 걸러 줌.

### 알림 만들기
- `diffPlayerNotices(prevPlayers, nextPlayers, at)` → 살아 있다가 죽음/끊김으로 바뀐 사람마다 알림 줄 1개.
- 처음 들어올 때(이전 명단 없음)는 알림 안 만듦.

### 초상 띠 → 카드 메뉴
- 초상 누름 → `openMenu(id)`, 초상 노드는 `registerAnchor(id, node)`.
- 내 초상 길게 누름 → 이모티콘 팔레트 열기 (지금 Board와 같은 훅).
