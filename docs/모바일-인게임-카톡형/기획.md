# 모바일 인게임 카톡형 기획 초안

## 한 줄 요약
폰 세로 인게임 화면을 채팅 중심(카톡형)으로 바꿈. 그림 분위기는 지금 그대로.

## 누가, 왜
- 팀원이 제안함.
- 지금 폰 세로 화면은 위 카드 판, 아래 양피지 채팅 틀로 나뉘어 채팅 칸이 좁음. 말이 많이 오가는 낮 토론 때 읽기 힘듦.

## 쓰는 장면 (스토리의 뼈대)
화면 위에서부터:
1. 맨 위 얇은 한 줄: "제 2일 · 낮 토론 · 0:45" (누르면 진행 바 펼침)
2. 초상 띠: 초상 누르면 지금 카드 메뉴, 띠 펼치면 카드 판 크게
3. 채팅방: 화면 대부분
4. 맨 아래: 입력칸 + 옆에 투표·행동 버튼

## 성공하면
- 낮 토론 때 말이 많이 오가도 한 화면에서 편하게 읽고 씀.
- 키보드가 올라와도 입력칸과 마지막 말이 보임.
- 투표·밤 행동·연출·결과까지 한 판이 끝까지 감.

## 제약
- 모바일 폰 세로만 바꿈.
- 서버·데스크톱·태블릿은 그대로.
- 지금 그림(양피지 틀, 어두운 가면무도회 배경)에서 크게 안 벗어남.
- 화면 전체를 덮는 연출(역할 공개·밤·재판·추방)은 그대로.
- 마피아42는 "채팅 중심 메신저형 배치"라는 생각만 가져옴. 그 게임 그림·이름·생김새는 안 따라 함.

## 고른 방향 (버린 안과 이유)
- 고름: 채팅방 하나에 다 쌓고 표시로 구분 (조커 채팅 색·표시, 시스템 알림 가운데 회색 줄).
- 버림: 채널별 탭 — 밤에 오가기 번거로움.
- 버림: 연출을 채팅 메시지로 바꾸기 — 일이 너무 커짐.

## 숨은 가정 (확인할 것)
- 지금 모바일 채팅·카드 메뉴·투표 현황 창·연출을 그대로 가져다 쓸 수 있음.
- 10명 판에서도 초상 띠 한 줄로 충분함.

## 첫 버전 범위
스토리 1~8 전부: 판 들어오기, 위 단계 줄, 초상 띠, 낮 토론 채팅(말풍선), 이모티콘(채팅방 + 띠), 투표·재판, 밤 행동·조커 채팅, 죽음·알림·게임 끝.

## 나중에
- 폰 가로 — 회의 뒤에 정함.

## 안 하는 것 (이유)
- 태블릿 바꾸기 — 화면이 커서 데스크톱처럼 두면 됨.
- 데스크톱·서버 바꾸기 — 이번 범위가 모바일만.
- 연출 바꾸기 — 그대로 두기로 함.
- 그림 분위기 바꾸기 — 게임 분위기 유지.

## 아직 모르는 것
- 초상 띠를 펼쳤을 때 채팅방을 얼마나 가릴지.
- 조커 채팅 구분 색·표시의 생김새.
