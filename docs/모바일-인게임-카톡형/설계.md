# 설계

브랜치: `feature/mobile-ingame-talk` (origin/refactor/ui-update3 78e0fb8e 위)

## 도구
| 항목 | 고른 것 | 이유 | 버린 안 |
| --- | --- | --- | --- |
| 화면 | 지금 모바일 그대로 (React 19·Tailwind 4·zustand) | 새로 설치할 것 없음 | 채팅 UI 라이브러리 |
| 시험 | node 기본 시험 도구(`node --test`) | 설치 없이 섞기 같은 순수 로직만 시험 | vitest 새로 설치 |

## 폴더
```
frontend-mobile/src/domains/game/ingame/
 ├─ components/talk/   카톡형 화면 부품 (폰 세로 전용)
 ├─ hooks/talk/        카톡형 데이터 훅 (채팅·알림·이모티콘 모으기)
 └─ utils/talk/        순수 함수 (섞기·알림 문구) — 시험 대상
frontend-mobile/tests/talk/  utils/talk 시험
```
- 폰 세로 판정: `useWideChat() === false` (land 아님, md 아님). 그때만 TalkLayout, 아니면 지금 GRID 그대로.
- 연출 위치용 `data-slot="top"`, `data-slot="timebar"`는 새 배치에도 붙임.
- 데스크톱 것 그대로 씀: 채팅 세션 컨텍스트, 참가자 컨텍스트, 카드 메뉴 훅, 이모티콘 보내기·말풍선 스토어, useTimebar, 연출 층, 재판 채팅, 입력 줄(Composer + ShellBottom).

## 데이터 모양 — 채팅방 한 줄
| 칸 | 코드 | 뜻 |
| --- | --- | --- |
| 종류 | `kind` | `'chat'` 말 / `'system'` 알림 / `'emoji'` 이모티콘 |
| 고유 번호 | `id` | 목록 key |
| 시각 | `at` | 밀리초 |
| 보낸 사람 | `playerId`, `name` | 알림엔 없음 |
| 내 것 | `mine` | 오른쪽에 그림 |
| 조커 채팅 | `joker` | 밤 채팅 |
| 내용 | `text` / `itemId` | 글·알림 문구 / 이모티콘 번호 |

## 코드 규칙 (이번 작업)
- 파일당 300줄 아래(ESLint 규칙), 파일 하나에 일 하나.
- 소켓·HTTP 직접 호출 금지 — 데스크톱 훅만 씀.
- 이미 있는 부품부터 씀(Portrait, CardSheet, EmojiPalette, Composer).
- 주석은 이유만, 개조식 명사형.

## UI 방향
- 지금 그림 분위기 유지: 어두운 배경, 양피지·금빛 테두리 색.
- 말풍선: 남 = 어두운 양피지색, 나 = 금빛 쪽, 조커 채팅 = 붉은 기.
- 시스템 알림: 가운데 반투명 회색 줄.
- 누르는 칸 44px 이상, 글자 크기 설정(app-text-scaled) 따라감.
