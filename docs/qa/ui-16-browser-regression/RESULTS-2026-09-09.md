## 결함

### BUG-UI16-01 — `/multiplay` "입장하기" 버튼이 사운드 컨트롤 위젯에 가려짐
- 재현: 멀티플레이 목록에서 방 행을 선택 → 우하단 "입장하기" 버튼 클릭. Playwright 클릭이 `div.absolute.bottom-4.right-4`(사운드 컨트롤 이미지)에 가로막혀 실패(`subtree intercepts pointer events`). 실사용자도 같은 영역을 눌러 입장하지 못한다.
- 화면: `12-BUG-enter-button-covered.png`
- 우회: 자동화는 버튼 핸들러 직접 호출. 수정은 사운드 컨트롤 위치/z-index 또는 입장 버튼 배치 조정(UI-08 범위).

### BUG-UI16-02 — 결과 화면 로스터·MVP가 비어 있음
- 화면: `60-result-mvp-p01.png` — "가면무도회 참가자 정체" 패널에 진영 배지만 있고 참가자 행·MVP 없음.
- 원인: 로컬 서버 `evaluateWinCondition`이 `winResult = { winner }`만 만들고(`backend/game-core/gameSession.js:261`), 원격 계약의 `reveals[]`(uuid·nickname·role·team·alive)·`mvp`를 내려주지 않는다. `buildGameResultViewModel`은 `reveals`가 없으면 빈 로스터를 만든다(파일 상단 주석에 명시).
- 수정 방향: 백엔드가 ENDED 시 `winResult.reveals`(전원 정체)와 `mvp`를 채우도록 확장(백엔드 변경이므로 UI 배치 범위 밖).

### BUG-UI16-03 — 결과 화면 "로비로" 클릭 후 이동하지 않음 (미확인)
- 재현: `60-result-mvp-p01.png` 상태에서 "로비로" 클릭 → 2.5초 후에도 `/gameresult`(`61-back-to-lobby.png`).
- 버튼은 로컬 `useInGameExit().requestExit`에 연결돼 있다. 서버 ack 실패인지, ENDED 이후 세션 정리 경로 문제인지는 콘솔·소켓 로그를 확인하지 못했다. 재현 시 네트워크 탭 확인 필요.

## 재실행 방법

```bash
docker compose up -d db
# backend: npm --prefix backend run dev / frontend: npm --prefix frontend run dev
node docs/qa/ui-16-browser-regression/harness/phaseA.mjs
node docs/qa/ui-16-browser-regression/harness/phaseC.mjs   # 5인 한 판 → 결과 화면
```

- 판을 다시 돌리기 전에 backend를 재시작해야 한다(이전 게임 세션이 메모리에 남아 방 생성·입장이 막힘).
- 하네스는 `C:/dev/pluto-ide/node_modules/playwright-core`와 `%LOCALAPPDATA%/ms-playwright/chromium-1234`를 사용한다.
