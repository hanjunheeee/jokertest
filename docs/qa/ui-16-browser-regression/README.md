# UI-16 브라우저 회귀 검증 — 스크린샷 없음

이 디렉터리는 `docs/qa/ui-16-browser-regression.md`의 단계별 스크린샷을 담을 자리다.

이번 실행(2026-09-09, pluto 슬라이스 AK, 검토 반려 후 2차 확인 포함)에서는 실제 브라우저
조작이 불가능해 어떤 단계도 수행하지 못했고, 그 결과 스크린샷도 없다. 자세한 사유와 이번
2차 확인에서 다시 검증한 근거는 상위 문서의 "왜 미검증인가"·"2차 확인에서 다시 검증한 것" 절을
참고한다.

다음에 실제 브라우저 환경에서 재실행할 때는 이 디렉터리에
`<단계번호>-<계정 라벨>-<방코드 또는 gameId>.png` 형식으로 스크린샷을 채우고(예:
`04-accountA-g_a1b2c3.png`), 상위 문서의 단계별 표에서 각 행의 판 식별자·스크린샷·결과 칸을
갱신한다. QA3·QA4 스크린샷은 반드시 같은 gameId를 파일명에 써서 동일 판임을 증명해야 한다 —
자세한 규칙은 상위 문서의 "판 식별자(방코드·gameId) 연결 프로토콜" 절 참고.
