# 모바일 광고 기획

모바일 웹 앱(frontend-mobile)에 광고 2곳 붙이기. 사용자 요청: "기능 하나만 광고 띄우기, 하단에 하나, 게임 한 판 끝나면 하나".

## 무엇
- **하단 배너**: 화면 맨 아래 광고 한 줄 (320×50, 위로 8px 띄움, 전체 높이 58px)
- **한 판 끝 광고(전면)**: 결과 화면에서 한 번, 화면 전체를 덮는 창 안에 광고 + "5초 뒤 닫기" → 닫기 버튼

## 왜
- 게임 흐름은 안 끊고 수익 자리만 만들기
- 배너는 게임 바깥 화면에만, 전면은 판이 끝나 쉬는 때에만

## 하단 배너 보이는 곳 / 안 보이는 곳
| 보임 | 안 보임 |
|---|---|
| 로비 `/lobby` | 인게임 `/ingame` (카톡형 입력칸을 가림) |
| 모드 고르기 `/gameMode` | 로그인·가입 `/`, `/login` |
| 방 목록·코드 `/multiplay`, `/roomInvite` | 계정 찾기 `/find-id`, `/password-reset`, `/password-reset/request` |
| 방 만들기 `/game-setup` | 개발 미리보기 `/dev/...` |
| 대기방 `/game-matching` | 새로 생긴 화면 (목록에 넣기 전까지) |
| 마이페이지·이모티콘·계정 `/mypage`, `/mypage/emoticons`, `/account` | |
| 상점 `/store`, 서고 `/library`, 설정 `/setting` | |
| 결과 `/gameresult` | |

- 목록: `frontend-mobile/src/shared/ads/bannerRoutes.js` (허용 목록 방식)
- 바닥 버튼 줄(ShellBottom) 아래에 붙고, 페이지 높이가 그만큼 줄어듦
- 우하단 고정 뒤로 버튼(BottomBackFixed)은 배너 높이만큼 위로 올라감
- 시트·모달(z 50 이상)은 배너 위를 덮음

## 한 판 끝 광고
- 결과 화면 연출 영상이 끝나고, 결과판·버튼이 다 나타난 뒤(1.5초) 한 번
- 판마다 한 번: 띄운 gameId를 기억, 같은 판으로 다시 들어와도 안 띄움
- 5초 동안 뒤 화면 조작·Esc·뒤로 가기 다 막힘, 5초 뒤 닫기 버튼·Esc·뒤로 가기로 닫힘

## 공급자 설정이 없을 때
- 운영(빌드): 광고 자리 자체가 없음 (빈 칸도 안 남김)
- 개발 서버: 회색 "광고 자리 (개발 화면만)" 상자만 보임
