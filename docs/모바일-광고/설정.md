# 모바일 광고 설정 방법 (AdSense)

값을 안 넣으면 운영 화면엔 광고가 아예 안 나옴. 개발 서버에선 회색 "광고 자리" 상자만 나옴.

## 1. AdSense 가입
1. https://adsense.google.com 에서 구글 계정으로 가입
2. 사이트 주소 넣기: 모바일 앱이 올라가는 진짜 주소 (예: `https://m.우리도메인`)
3. 지급 정보(주소·세금 정보) 채우기

## 2. 사이트 승인 받기
- AdSense가 주는 확인 코드를 사이트에 넣어야 함
  - 우리 앱은 환경값이 들어가면 `adsbygoogle.js?client=ca-pub-…` 스크립트를 스스로 넣음 → 이걸로 확인 가능
  - 또는 AdSense 화면의 "ads.txt" 방식 사용 (아래 3번)
- 승인까지 며칠~몇 주 걸림
- **승인 전엔 진짜 광고가 안 뜸** (빈 칸 → 우리 앱은 자리를 접음)
- 로그인해야 보이는 화면만 있으면 심사에서 "내용 부족"으로 떨어질 수 있음 → 로그인 없이 보이는 소개 화면이 있으면 좋음

## 3. ads.txt 올리기
- AdSense 화면 → 사이트 → ads.txt 에 나오는 한 줄 복사
  - 모양: `google.com, pub-숫자, DIRECT, f08c47fec0942fa0`
- 사이트 맨 위 주소에 `ads.txt` 파일로 올리기 (예: `https://m.우리도메인/ads.txt`)
  - 모바일 앱은 `frontend/public` 그림 폴더를 같이 씀 → 거기에 `ads.txt`를 넣으면 빌드에 같이 들어감
- 안 올리면 광고 수익이 줄거나 막힐 수 있음

## 4. 광고 단위 2개 만들기
AdSense → 광고 → 광고 단위 기준 → 디스플레이 광고

| 이름(예) | 모양 | 크기 | 어디 넣나 |
|---|---|---|---|
| 모바일 하단 배너 | 디스플레이 | **고정 320×50** | `VITE_ADSENSE_SLOT_BANNER` |
| 모바일 한 판 끝 | 디스플레이 | **반응형** | `VITE_ADSENSE_SLOT_INTERSTITIAL` |

- 만들면 나오는 코드에서 `data-ad-slot="숫자"`의 숫자가 광고 단위 번호
- `data-ad-client="ca-pub-숫자"`가 광고 계정 번호
- **자동 광고는 켜지 않기** (인게임 화면에 멋대로 붙어 입력칸을 가릴 수 있음)

## 5. 환경값 넣기
`frontend-mobile/.env` (깃에 안 올라감) 또는 배포 서버 환경값에:

```
VITE_AD_PROVIDER=adsense
VITE_ADSENSE_CLIENT=ca-pub-여기에계정번호
VITE_ADSENSE_SLOT_BANNER=여기에배너번호
VITE_ADSENSE_SLOT_INTERSTITIAL=여기에한판끝번호
```

- Vite 값이라 **빌드할 때** 들어감 → 값 바꾸면 다시 빌드
- 하나만 넣으면 그 자리만 나옴 (예: 배너 번호만 넣으면 한 판 끝 광고는 없음)
- 끄려면 `VITE_AD_PROVIDER`를 비우고 다시 빌드

## 6. 정책 주의 (어기면 계정 정지)
- **실수 클릭 유도 금지**: 버튼 바로 옆·바로 아래 광고 금지
  - 우리 배치: 배너는 바닥 버튼 줄과 8px 띄우고 선으로 나눔, 고정 뒤로 버튼은 배너 위로 올림
  - 한 판 끝 창: 닫기 버튼은 광고 아래로 띄우고 5초 뒤에만 나옴
  - 화면을 새로 바꿀 때 버튼을 배너에 더 붙이지 않기
- **게임 화면 광고**: 게임 진행 화면(인게임)엔 광고 안 붙임 — 조작하다 잘못 누르기 쉬움
- **광고 눌러 달라는 말 금지**: "광고 눌러 주세요", 광고 쪽 화살표 등
- **자동 새로 고침 금지**: 광고 칸을 시간마다 새로 바꾸지 않기 (우리 코드는 안 함)
- **광고 위 덮기 금지**: 광고를 다른 그림·버튼으로 가리지 않기
- 광고 이름표는 "광고"만 씀 (허용된 말)
- 내 광고를 내가 누르지 않기 (개발 중엔 개발 서버 회색 상자로 확인)
