# 모바일 광고 결정

## 1. 공급자: Google AdSense
- 모바일 웹 앱(브라우저)이라 앱 전용 AdMob은 못 씀 → 웹용 AdSense
- 수동 광고 단위 2개만 씀 (자동 광고는 끔: 인게임 화면에 멋대로 붙을 수 있음)

## 2. 환경값 (이름만, 값은 파일에 안 넣음)
| 이름 | 뜻 |
|---|---|
| `VITE_AD_PROVIDER` | `adsense` 또는 비움 |
| `VITE_ADSENSE_CLIENT` | 광고 계정 번호 `ca-pub-숫자` |
| `VITE_ADSENSE_SLOT_BANNER` | 하단 배너 광고 단위 번호 |
| `VITE_ADSENSE_SLOT_INTERSTITIAL` | 한 판 끝 광고 단위 번호 |

- 공급자·계정 모양이 틀리면 광고 안 씀 (`readAdConfig`)
- 자리마다 광고 단위가 있어야 진짜 광고, 없으면 운영은 없음·개발은 회색 상자 (`slotMode`)

## 3. 스크립트는 설정 있을 때만 한 번
- `adsbygoogle.js?client=` 를 처음 광고 칸이 그려질 때 한 번만 넣음
- 넣기 실패(광고 막기·인터넷 끊김)면 자리 접힘, 다음 화면에서 다시 시도
- AdSense가 `data-ad-status="unfilled"`(광고 없음) 표시하면 자리 접힘
  - 배너: 줄째 사라지고 페이지 높이 원래대로
  - 전면: 창 바로 닫힘

## 4. 하단 배너 자리
- 화면 틀(MobileShell) 맨 아래, 바닥 버튼 줄 **아래**
  - 이유: 버튼 줄은 엄지 닿는 곳이라 그대로 두고, 광고는 더 아래 가장자리로
- 광고 위로 8px 띄우고 가는 선 → 버튼과 바로 붙지 않게 (실수 클릭 줄이기)
- 홈 막대 안전 영역은 화면 틀 아래 여백이 이미 비킴
- 고정 뒤로 버튼·모드 카드 크기는 CSS 변수 `--mobile-ad-h`(배너 높이 + 안전 영역)로 비킴, 배너 없으면 0
  - `:has()`로 배너가 있을 때만 값이 생김 (iOS 15.4·크롬 105 이상)
- 크기: 320×50 고정 (모바일 배너 표준, 높이가 일정해야 화면이 안 흔들림)
- 허용 목록 방식: 새 화면은 일부러 넣기 전까지 배너 없음 (인게임 같은 곳에 실수로 안 붙게)
- 허용 화면끼리 옮겨 다니는 동안 광고 칸은 그대로 (화면마다 새로 고침 안 함 → 정책상 자동 새로 고침 금지)

## 5. 한 판 끝 광고 때
- **결과 화면 첫 연출(승패 영상 → 결과판·버튼 나타나기)이 끝나고 1.5초 뒤**로 정함
- "대기방으로/로비로 누를 때"를 안 고른 이유
  - 대기방으로는 같은 방 사람들과 함께 돌아가는 시간 맞춤 동작 → 광고로 늦추면 방 흐름이 어긋날 수 있음
  - 버튼 누른 직후 바로 광고가 뜨면 같은 손가락으로 광고를 잘못 누르기 쉬움 (정책 위반 위험)
  - 결과를 다 본 뒤 쉬는 때라 덜 방해됨
- 판마다 한 번: gameId를 localStorage(`mmc.ads.seenGames`, 최근 30판)에 **열 때 바로** 기억
  - 닫기 전에 화면을 떠나도 다시 안 띄움
  - 저장소가 막힌 브라우저면 이번 접속 동안만 메모리로 기억
  - 개발 미리보기(`/gameresult?outcome=win`)는 `preview:win`으로 기억 (개발 서버에서만)
- 크기: 폭 맞춤 반응형, 높이 250 이상 (작은 폰 폭 320에서도 안 넘치게)

## 6. 닫기 막기
- 5초 동안: 뒤 화면 막(어두운 덮개)이 눌림을 다 받음, Esc 무시, 뒤로 가기는 그 자리에 머묾
- 5초 뒤: 닫기 버튼(양피지 확인 버튼 그림)·Esc·뒤로 가기로 닫힘
- 뒤로 가기 처리
  - 열 때 같은 주소 칸을 하나 더 쌓음 → 뒤로 가기가 그 칸만 빼게
  - 결과 화면은 원래 뒤로 가기를 막고 "게임에서 나가시겠습니까?"를 띄움(데스크톱 훅 useBlocker)
    → 광고 칸 뒤로 가기가 라우터에 가면 확인 창이 뜨고, 같은 칸이라 새로고침까지 됨
  - 그래서 `backGate.js`로 popstate를 라우터보다 먼저 받아 광고 창이 열린 동안만 가로챔
    - window의 popstate는 등록 순서대로 불림(capture 써도 순서 안 바뀜, 크롬에서 확인) → main.jsx에서 App보다 먼저 불러 등록
  - 닫기 버튼·Esc로 닫으면 쌓은 칸을 조용히 한 칸 되돌림 (라우터는 모름)

## 7. 확인한 것
- 순수 로직 시험 14개 (`frontend-mobile/tests/ads/`): 설정 읽기, 화면별 배너, 판마다 한 번, 5초 셈
- 개발 서버 390×844: 로비·모드 고르기·마이페이지·서고·상점·설정·방 만들기에 배너, 인게임·로그인엔 없음
- 결과 화면은 판 없이 `?outcome=` 미리보기로 확인 (진짜 판 gameId 경로는 시험으로만 확인)
- 헤드리스 크롬으로 확인: 5초 전 뒤로·Esc는 그대로, 5초 뒤 뒤로·Esc는 닫힘, 나가기 확인 창 안 뜸, 같은 판 다시 들어오면 안 뜸
- 진짜 AdSense 광고는 계정·사이트 승인 전이라 못 봄
