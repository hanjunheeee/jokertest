# joker-S2 · 공동 행동 리졸버 범용화

## 확정 스펙 (전제)

- 의존: S1-1 (턴 구조 위에서 동작)
- 합의 규칙 (Q2 확정): 전원 같은 대상 = 확정 / 지목 + 건너뛰기 = 지목 확정 (건너뛰기는 위임) / 서로 다른 지목 = 기권 / 전원 건너뛰기 = 기권

## 요구

1. 공용 리졸버를 만든다: 같은 직업 N명의 제출을 받아 단일 대상 또는 기권을 산출. 규칙은 위 확정 스펙.
2. 광대·의사·경비원·WH 전부 이 리졸버를 사용한다. 광대의 기존 투표 집계(gameSession.js :734-758)를 리졸버로 추출하고, 의사의 합집합 보호(:763-773), 경비원·WH의 개별 행동(:778-792)을 제거한다.
3. WH 2명일 때 결과는 확정된 단일 대상 1건이며, 두 WH 모두에게 통지된다.
4. 한 명이 사망·이탈 상태면 남은 인원의 제출만으로 확정한다.

## 성공 조건

- 의사 2명이 다른 대상 지목 시 아무도 보호되지 않는다 (9.1)
- WH 2명이 다른 대상 지목 시 조사 기권, 같은 대상이면 결과가 2명 모두에게 간다 (4.2.6)
- 광대의 기존 동작이 회귀 없이 유지된다 (4.1.3)
- 직업 인원 1명일 때 그 1명의 제출이 그대로 확정된다
