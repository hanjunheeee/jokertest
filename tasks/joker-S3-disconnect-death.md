# joker-S3 · 접속 끊김 개별 사망

## 확정 스펙 (전제)

- 의존: S1-2 (턴 타이머 위에 유예가 얹힘), S2 (남은 인원 확정 규칙)
- 끊김은 세션 종료 사유가 아니다 — 개별 플레이어의 문제로 격리한다
- 끊김 사망은 사실만 공개하고 역할은 비공개
- 재접속 식별은 플레이어 UUID 기준 (기존 구현 존재 추정 — 계획 단계에서 현황 확인, 없거나 불충분하면 1안 제시)
- **사망 확정 후 재접속은 불가** — 유예를 넘겨 사망 처리된 플레이어는 그 세션에 다시 들어올 수 없다 (관전 복귀 없음)

## 요구

1. 끊김 발생 시 세션을 종료하지 않는다 (:1357-1393의 전체 종료 제거). 해당 플레이어를 재접속 대기 상태로 표시한다.
2. 밤 자기 턴 중 끊김: 해당 턴 제한시간 내 재접속하지 않으면 사망 확정. 그 외 시점 끊김의 유예 기준은 계획 단계에서 1안 제시 후 승인받는다 (권장: 현재 페이즈 종료 시점까지).
3. 끊김 사망은 사실만 공개하고 역할은 비공개한다.
4. 끊김 사망 직후 승리 조건을 재평가한다 (>= 판정이므로 다인 감소에도 정상 동작 확인).
5. 같은 직업 2명 중 1명 끊김 시 S2 리졸버가 남은 1명 제출로 확정한다.
6. 재접속 시 현재 페이즈·자기 상태·수신 가능 채널 기준으로 상태를 복원한다. 브라우저 새로고침(F5)도 동일 경로로 복원되어야 한다.
7. 사망 확정된 플레이어의 재접속 시도는 거부한다 — 세션 참여 불가 안내와 함께.

## 성공 조건

- 플레이어 1명 강제 종료 시 게임이 계속 진행된다 (10.1 / 9.3)
- 밤 턴 중 끊김 → 시간 내 미복귀 → 사망·기권 처리 후 진행 (10.2)
- 끊김 사망 공개에 role이 없다 (10.3 유지)
- 마지막 시민측 1명 끊김 사망 시 즉시 광대 승리로 종료된다 (10.4)
- 재접속·타이머 만료 동시 발생 시 이중 사망/이중 진행이 없다 (레이스 테스트 필수)
- 게임 중 F5 새로고침 후 현재 페이즈·자기 역할·채널이 그대로 복원된다
- 사망 확정 후 재접속 시도가 거부된다
