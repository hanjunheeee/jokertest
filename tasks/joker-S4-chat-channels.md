# joker-S4 · 채팅 채널 재설계

## 확정 스펙 (전제)

- 권한 매트릭스: 밤 = 직업별 채널, 각 직업 생존자끼리만 (시민 포함) / 낮 = 생존자는 DAY 전송 가능, 사망자는 DAY 열람만 / 밤 사망자 = 아무 채널도 열람·전송 불가 — **단 하나의 예외: 죽은 광대는 JOKER 채널 열람·전송 가능** (광대만의 특례, 확정 스펙. 다른 직업의 사망자는 예외 없음)
- 채널 권한은 백엔드가 강제한다 — 프론트 우회로 다른 채널 수신·전송이 불가능해야 한다

## 요구

1. 밤 채팅을 직업별 채널로 격리한다: 각 직업의 생존자끼리만 열람·전송 가능 (시민 포함). 기존 JOKER 전용 채널을 이 구조로 일반화한다.
2. 낮: 생존자는 DAY 채널 전송 가능, 사망자는 DAY 채널 열람만 가능 — 현행 DEAD 채널 전송을 제거하거나 열람 전용화한다.
3. 밤: 사망자는 어떤 채널도 열람·전송 불가 (joker-B의 프론트 차단을 백엔드에서도 강제). 예외는 죽은 광대의 JOKER 채널 하나뿐이며, 이 예외도 백엔드 권한 규칙에 명시적으로 구현한다.
4. 채널 권한 검증을 소켓 라우팅 층에서 수행한다 — 구독·발행 모두.

## 성공 조건

- 밤에 각 직업이 자기 직업 채널만 보이고, 타 직업 메시지가 소켓 레벨에서 오지 않는다 (7.3 / 7.5)
- 낮 사망자가 메시지를 보낼 수 없다 (7.2)
- 밤 사망자에게 어떤 채팅 이벤트도 전송되지 않는다 — 죽은 광대의 JOKER 채널만 예외로 동작한다 (7.4 / 7.6 백엔드)
- 조작된 클라이언트가 타 채널 구독·발행을 시도해도 거부된다
