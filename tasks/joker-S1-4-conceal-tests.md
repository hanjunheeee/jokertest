# joker-S1-4 · 은폐 회귀 테스트 고정

## 확정 스펙 (전제)

- 은폐 원칙: 관전자(이벤트 스트림 수신자) 관점에서 어느 직업이 전멸했는지 알 수 없어야 한다
- 즉시 진행 규칙 하에서의 판정 기준: **payload 필드·값 형태로는 구별 불가** + **죽은 직업 턴의 길이가 그럴듯한 범위(제한시간의 20~60%) 안** — "항상 풀타임 = 전멸"이라는 역신호가 없어야 한다

## 요구

1. "직업 X 전멸 상태의 밤 이벤트 스트림"과 "X 생존 상태에서 전원이 기권(건너뛰기)한 밤 이벤트 스트림"을 비교해, payload 필드 구성·값 형태가 구별 불가능함을 검증하는 자동 테스트를 추가한다.
2. 죽은 직업 턴의 종료 시점이 제한시간의 20~60% 범위에 들어옴을 검증한다 (여러 회 반복해 범위·무작위성 확인).
3. 과거 conceal 회귀(8/27 수정분)를 커버하는 케이스를 포함한다.

## 성공 조건

- 위 테스트들이 스위트에 포함되어 통과한다
- 이후 슬라이스가 밤 이벤트를 건드려 은폐를 깨면 이 테스트가 실패한다 (의도적으로 payload에 생존 정보를 넣어 실패를 1회 확인 후 되돌리는 것으로 검증)

## 성공 조건에 넣지 말 것 (범위 밖 — 수정 금지)

- 프로덕션 코드 동작 변경 — 이 슬라이스는 테스트 추가만. 테스트가 기존 코드의 은폐 결함을 발견하면 수정하지 말고 반송으로 보고한다

## 자잘한 규칙

- 변경 범위: backend 테스트, 필요 시 프론트 유닛 테스트
