# jokertest 슬라이스 실행 순서 (2026-08-29 최종본)

A는 merge 완료. 아래 전부 **직렬 — 병렬 금지** (대부분 gameSession.js 또는 같은 계층을 건드림).
각 슬라이스 merge 후 다음 발사. 반송 2회면 그 항목만 대화형으로 전환.

## 본선 (버그 수리 → 구조)
1. joker-B-frontend-display — 프론트 표시 4건 (죽은 광대 JOKER 채널 예외 반영본)
2. joker-L1-room-code-join — 방 코드 입장 배선 (독립적, 데모 거리)
3. joker-C-day-phases — 낮 토론/투표 분리 (전원 기권=밤, 처형 즉시 재평가 반영본)
4. joker-D-night-resolution — 밤 해소 규칙 (실패 통지·보호 소멸·조사 독립·사망 즉시 재평가)
5. joker-S1-1-night-turn-engine — 서버 밤 턴 엔진 (확정 스펙 전제 포함)
6. joker-S1-2-timers — 타이머·타임아웃·설정 소비 (소프트락 제거)
7. joker-S1-3-frontend-turns — 프론트 턴 연동
8. joker-S1-4-conceal-tests — 은폐 회귀 테스트 고정
9. joker-S2-joint-resolver — 공동 행동 리졸버
   → 이 다음 T1(테스트 파일 분할) 검토 — 요구사항은 그때 작성
10. joker-S4-chat-channels — 채팅 채널 재설계 (광대 예외 반영본)
11. joker-S3-disconnect-death — 끊김 개별 사망 (사망 후 재접속 불가·F5 복원 반영본, 반송 확률 최고)

## DB·인프라 (본선과 독립 — A~C 사이 어디든 끼워도 됨, 직렬만 유지)
- joker-DB1-startup-pool — 연결 실패 exit 1 + 풀 명시 (제일 작고 급함)
- joker-DB2-account-paths — 가입 트랜잭션·닉네임 409·sessionId 검증
- joker-DB3-tables-cleanup — 결과·집계 테이블 선생성 + sqlite 고아 정리
- joker-MM1-ingame-room-guard — 게임 중 새 방 참가 차단 (Codex 발견)
- joker-INFRA1-docker — Dockerfile·env 복구 (최종 기동 확인은 수동)

## 데이터 (DB3 이후)
- joker-M1-concurrent-users — 동접 스냅샷 (DB3의 테이블 사용)
- joker-R1-match-results — 경기 결과+user_stats 저장 (교차 조사 결론 반영: ENDED 즉시·공통 함수·idempotency·중단=이탈자 패배)

## 수동 할 일 (슬라이스 아님)
- Cloudflare R2 키 회전 (.env 평문 발견)
- 마이그레이션 baseline 복구는 "기존 테이블을 바꿔야 하는 첫 순간" 착수
